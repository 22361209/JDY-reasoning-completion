# 项目接手指南

这份文件供新的开发者或 Codex 任务快速确认项目定位、当前真相源和开工顺序。

## 一句话目标

持续完善面向控制臂/摆臂工厂的 ERP：先保证业务闭环、数据正确性、安全、tenant 隔离、可用性和可维护性，再用 JDY 资料校准术语、信息架构、常用交互与视觉基线。

本仓库不是 JDY 的像素级镜像，也不因参考系统已有功能而自动获得实施授权。

## 定位与优先级

`JDY-复刻-local` 是调研与参考资料库；本仓库是当前 ERP 的实现与演进仓库。优先级由 ADR-015 固定：用户确认的业务决策与本项目的数据一致性、安全、tenant、权限、生命周期规范，优先于 JDY 参考和外观相似度。

## 先读什么

1. [`docs/README.md`](README.md)：按角色选择现行文档。
2. [`docs/09-交接清单.md`](09-交接清单.md)：唯一当前快照。
3. [`docs/12-当前批次验收清单.md`](12-当前批次验收清单.md)：唯一当前任务包；没有完整范围、预算、门禁和停止条件不得开工。
4. 与任务直接相关的架构/规则文档与代码；不要重读全部历史报告。
5. 仅在任务确有 JDY 参考需求时，再读取对应调研资料、截图或字段地图。

## 当前真相源

- `config/effective-feature-scope.json`：当前有效范围（生成物）。
- `config/feature-delivery-status.json`：A0–A4 交付状态、证据和已知缺口。
- `config/regression-manifest.json`：smoke / area / full 的受版本控制回归归属。
- `docs/09-交接清单.md`：当前状态和下一步。
- `docs/12-当前批次验收清单.md`：当前任务的允许路径、明确不做、验收和预算。

不得从菜单、历史批次、ignored `verification/` 文件或 JDY 截图推断当前完成度。

## 不要做的事

- 不以 JDY 存在某功能为由直接扩范围。
- 不把已关闭任务合同或历史验收报告改写成当前状态。
- 不缓存库存、单据、资金或报表等业务结果。
- 不让业务模块绕过应用服务直接修改库存、资金或其他模块的数据表。
- 不将业务规则堆进 Controller 或前端页面。
- 不在未立项时引入微服务、审批流、成本核算、汇率换算等复杂度。

## 开工与收尾

遵守 `AGENTS.md`：每个任务先声明范围、预算、停止条件和验收；只运行与改动相称的门禁；独立 review、验收、commit，用户明确要求后才 push。详细规则见 [`docs/guides/codex-execution-policy.md`](guides/codex-execution-policy.md)。
