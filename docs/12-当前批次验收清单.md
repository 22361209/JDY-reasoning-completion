# A183 当前任务包

## 目标

关闭 A182 真实 Chrome 终验留下的两项现场失败，并收口同一路径已确认的权限合同错位：

1. 资金转账单能够稳定加载已审核、启用且币种为 CNY/USD 的账户候选，真实用户可以完成同币种转账保存、审核、反审核和再审核。
2. 仅具备资金转账权限的角色能够读取完成转账所需的最小账户候选，但不会因此获得完整账户资料管理权限。
3. 盘点单在全新与既有浏览器状态下均明确显示“系统库存、实盘数量、差异”，且差异基准可审计。

## 范围外独立问题

- review 发现 `GET /api/cash-transfers/{billNo}` 既有路径没有声明资金转账权限，同 tenant 的任意已登录角色可能按可预测单号读取双方账户、金额与备注。该问题不是 A183 diff 引入，按本任务 `record-and-stop` 规则登记为独立 P1；本批不得借修候选权限之机扩大 Controller 修改面。
- 最终 review 保留 1 个 P3：账户候选的多页 offset 拉取虽然会校验总数稳定、分页非空和 ID 唯一，但无法识别页间恰好“删除 1 条并新增 1 条”、总数不变且 ID 仍唯一的并发快照漂移；页面可能暂时漏掉一个有效候选并保留一个已失效候选。保存/审核时后端仍会复验并以 409 阻断，因此不会错账。完整修复需要 selector API 提供稳定游标或快照 token，属于后端列表协议扩展，不在 A183 允许路径内，登记为后续独立低风险一致性任务。
