## 当前批次：A8 表单明细多行真实渲染

目标：把销售订单、销售出库、采购订单、采购入库表单从“数据已读入但界面主要显示第一行”推进到员工可编辑多行明细，支持新增、删除、逐行选择商品/仓库，并保持保存/审核/打开详情一致。

### 1. 明细表格

- [ ] 四类核心表单使用同一套明细行渲染范式。
- [ ] 每一行显示商品编码、商品名称、规格型号、仓库、数量、单价、金额。
- [ ] 多行数据打开详情后全部可见，不只显示第一行。
- [ ] 金额随数量、单价即时计算。

### 2. 行操作

- [ ] 支持新增明细行。
- [ ] 支持删除未保存或草稿单据的明细行。
- [ ] 已审核、已反审核、已作废、已红冲状态下明细行不可编辑。
- [ ] 商品/仓库选择器可按当前行回填，不串行。

### 3. 保存与详情一致性

- [ ] 保存草稿时提交全部明细行。
- [ ] 审核后再次从列表打开，明细行数量和金额与保存时一致。
- [ ] 销售出库、采购入库保留源订单号和全部明细。
- [ ] 查询列表打开详情不标记为未保存。

### 4. 验收

- [ ] `backend ./mvnw test` 通过。

- [ ] Playwright 新建一张至少 2 行采购订单，保存后列表打开详情验证 2 行均可见。
