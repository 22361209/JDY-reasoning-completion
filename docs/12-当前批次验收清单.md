# 当前任务包

## 目标

保留列表页的“列设置”“更新库存”并入动作按钮栏右侧、释放表格高度的目标；同时收口现场日常生产链演练发现的三项可用性问题：

- BOM 新增页的母件物料编码必须可选择已审核、启用且“可自制”的物料，并可靠回填母件快照。
- 基础资料增加“物料名称维护”入口；物料新增时名称仍必须从该主数据选择，未命中时可明确确认后转入新建名称。
- 物料列表和资料选择器不得在数据尚未加载完成时误显示“共 0 条”或把“加载中”当作可输入状态。

JDY：不作为本批实现参考；以当前 ERP 的主数据、BOM 与生产计划合同为准。

## 允许路径

- `frontend/src/components/DataListPage.vue` 的列表工具栏结构。
- `frontend/src/styles/base.css` 的列表工具栏与表格布局样式。
- `frontend/src/modules/master-data/**`、相关主数据服务/路由/导航与后端 application/controller/repository。
- `frontend/src/modules/production/**`、`frontend/src/components/BomEntryTable.vue` 与后端生产 BOM 查询/保存校验。
- 本批必要的 Flyway 迁移、针对性测试与 A166 验收报告、报告索引和交接快照。
- A166 的验收报告、报告索引与交接快照。

## 明确不做

- 不改变物料、BOM、生产计划、生产任务的审核与库存过账生命周期；不为选择器绕过后端已审核/启用守卫。
- 不扩展物料名称以外的新增主数据导入、批量维护、权限模型或产品属性体系。
- 不顺手重构无关列表或其他业务表单页面。
- 不运行 full，不 push。

## 验收与停止条件

- 标准列表中“列设置”“更新库存”位于动作栏右侧，原工具行不再占用高度。
- 支持明细视图的列表保留其切换入口，并同样位于右侧工具组。
- 按钮原有 `data-testid` 和行为保持可用；页面在当前 Chrome 本地 ERP 中复核。
- BOM 母件选择器只显示可自制、已审核、启用物料；选择后名称、规格、单位、默认仓库一致回填，后端再次校验。
- BOM 母件采用与子件分录一致的输入联想与 `...` 整表选择入口，不保留孤立的“选择”文字按钮。
- 新增物料名称可从前台入口维护；名称选择器未命中时明确提示，确认后进入新建名称，保存并审核后自动返回来源物料页、刷新选择来源并选中新建记录。
- 物料列表和下拉来源在加载期间显示加载状态，不把未完成请求渲染成业务空数据。
- 运行前端构建、`smoke`、`area:master-data`、`area:production`、必要后端针对性测试和文档治理检查各一次；若出现范围外失败则记录并停止，不顺手修复。
