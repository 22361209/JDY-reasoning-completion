## 当前批次：A14 下推数量批量调整

目标：下推确认弹窗支持清零、全剩余、按比例批量调整，让员工处理多行订单下推时不用逐格修改本次数量。

### 1. 清零/全剩余

- [x] 下推确认弹窗提供“清零”按钮。
- [x] 点击“清零”后，所有本次数量变为 0。
- [x] 下推确认弹窗提供“全剩余”按钮。
- [x] 点击“全剩余”后，所有本次数量恢复为剩余数量。

### 2. 按比例

- [x] 下推确认弹窗提供比例输入框。
- [x] 点击“按比例”后，本次数量 = 剩余数量 * 比例。
- [x] 比例结果保留两位小数。
- [x] 比例小于 0 或大于 100 时提示错误，不改动当前本次数量。

### 3. 草稿承接

- [x] 批量调整后的本次数量仍走原有超剩余校验。
- [x] 点击“生成草稿”后，下游草稿明细数量等于批量调整后的本次数量。
- [x] 本批未改后端库存/审核逻辑，A9 后端超量保护继续保留。
