# A181 当前任务包

## 业务目标

把 2026-08-09 在 BLD-TEST 通过 Chrome 真实用户路径复现的十个缺陷作为一个批次全部修复，不按严重度拆批或延期。修复后必须保持 tenant、审核才动账、反审核完整回滚、库存双写和用户可读错误等既有合同，并按原始可见界面步骤完成回归。

## 十项显式范围

1. 应付入库审核—反审核—重新审核与采购退货、付款组合后的事实和汇总余额正确。
2. 资金转账反审核后允许重新审核，不复用冲突事实键，也不向用户暴露原始 SQL 错误。
3. 盘点单以当前库存余额作为账面数量，并正确计算盘盈/盘亏差异。
4. BOM 禁止母件直接作为自身子件；保存、审核和重新审核均保持服务端守卫。
5. 调拨组织字段使用组织候选，不得打开仓库选择器；仓库字段继续使用仓库候选。
6. 新建并审核的物料名称能立即回填来源物料资料，且普通已审核启用名称可被精确检索。
7. 本次现场失败的采购订单表头备注保存后必须持久化并在重开时回显。
8. 销售报价反审核只显示报价生命周期文案，不声称冲销库存流水。
9. 应收明细把 `AR_FACT`、`RETURN_ALLOCATION`、`RECEIPT_ALLOCATION` 映射为用户业务文案。
10. 应付明细把 `AP_FACT`、`PAYMENT_ALLOCATION` 映射为用户业务文案。

## 允许路径

- `backend/src/main/**` 与上述财务、库存、生产/BOM、主数据和单据备注直接相关的应用服务、领域规则、持久化查询及必要 Flyway 迁移。
- `backend/src/test/**` 中上述十项行为的定向测试。
- `frontend/src/**` 中财务报表、库存盘点/调拨、BOM、物料资料、单据生命周期消息与备注直接相关的页面、服务和共享组件。
- `scripts/**` 中 A181 定向回归与既有相关回归的最小维护；如新增脚本，同步维护 `config/regression-manifest.json`。
- `docs/09-交接清单.md`、本任务包、A181 归档任务包、A181 验收报告及验收报告索引。
