- 修正仍手工指定业务单号的后端测试夹具，继续服从正式自动编号规则。

- 不手工 `INSERT`、`UPDATE` 或 `DELETE` `flyway_schema_history`；历史收敛只使用 Flyway 11.7.2 官方 `repair`，且必须先在备份恢复副本验证。
- 不开启 `outOfOrder`，不增加忽略迁移配置，不改写 V94/V95。
- 不处理 full 里的仓库夹具、UI 超时、财务断言等 71 项失败；它们属于后续回归基线批次。
- 不修改 A130 的 scope/status/manifest 结论。

1. 先备份当前 `jdy_erp` 数据库，并验证 archive、大小和 SHA-256。
2. 核对 Git 全历史：V90/V91 从未受版本控制，`4037847` 发布的是 V94/V95。
