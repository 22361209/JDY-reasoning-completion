## 当前批次：A17 分录 Excel 多行粘贴

目标：分录表支持直接粘贴 Excel/表格多行，让大量商品录入从逐格输入变成批量录入。

### 1. 粘贴解析

- [x] 商品编码输入框支持粘贴多行。
- [x] 仓库、数量、单价输入框同样支持粘贴多行。
- [x] 支持 Excel TSV 格式。
- [x] 兼容逗号/分号分隔。
- [x] 粘贴列顺序为 `商品编码 / 仓库 / 数量 / 单价`。

### 2. 分录落表

- [x] 从当前行开始覆盖已有行。
- [x] 粘贴行数超过当前剩余行数时自动追加行。
- [x] 粘贴后行金额和合计立即刷新。
- [x] 粘贴后提示已粘贴行数。
- [x] 保存草稿后，后端详情读回行数据一致。
