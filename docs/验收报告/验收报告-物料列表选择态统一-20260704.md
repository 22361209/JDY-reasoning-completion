# 验收报告：物料列表选择态统一

验收日期：2026-07-04

## 验收范围

本次收口把“物料弹窗”定义为 `product-master-list` 的列表选择态，禁止按单据局部再拼商品弹窗。

## 验收标准

- `product-master-list` 是物料资料正本，必须显示左侧物料类别分类器和右侧共享列表表格。
- 物料选择弹窗必须复用同一物料类别来源、同一 `product-master-list` 查询、同一共享选择器表格协议。
- 所有分录物料弹窗不得绕开 `MasterSelectorDialog -> SourceSelectorDialog -> product-master-list` 链路。
- 表格网格线只能由真实单元格边框绘制，不得叠加 body 背景横线造成错位。
- 物料选择后必须回填物料编码、物料名称、规格型号、单位、净重、毛重、物料类别等标准字段。
- 关键词、类别、分页、列筛选、列宽拖拽属于共享选择器/列表协议，不得写入单据 composable。

## 入口清单

已纳入统一物料选择态：

- 普通 `EntryTable` 分录物料选择：销售报价单、销售订单、发货通知单、采购订单、采购入库、采购退货、其他入库、其他出库、库存调拨、库存盘点、生产领料、生产入库。
- 销售出库单：独立 `useSalesOutDocument`，但弹窗入口同样走 `MasterSelectorDialog`。
- 物料资料列表：`product-master-list`，作为选择态正本。

当前登记为非弹窗物料查找点：

- BOM 维护：当前仍是专用表体/输入查找，不属于本次整列表弹窗；后续如改为弹窗，必须接入同一物料选择态。
- 委外加工单：当前仍有专用物料查找逻辑，不属于本次整列表弹窗；后续如改为弹窗，必须接入同一物料选择态。
- 库存期初、安全库存设置等直接录入物料编码的局部字段，当前不是整列表弹窗。

## 实现结果

- 新增 `ProductCategorySidebar`，作为物料资料列表和物料选择弹窗共用的类别侧栏。
- 新增 `useProductCategoryFacet`，统一从 `product-category-list` 加载已审核、启用类别。
- `DataListPage` 在 `product-master-list` 下显示左侧物料类别分类器，分类点击通过列表查询协议传入 `category` 条件。
- `MasterSelectorDialog` 的商品/物料选择改为复用同一类别侧栏，不再在弹窗内部散写类别加载 UI。
- 物料资料列表和物料选择弹窗的表体背景网格已关闭，改由真实单元格边框绘制行线。

## 遗留问题

- P3：`useProductCategoryFacet` 当前按 `product-category-list` 第 1 页、`pageSize: 500` 加载类别。若后续物料类别超过 500 条，物料资料列表和物料选择弹窗左侧分类器会缺少后续类别；后续应改为分页拉全，或接入专用类别树/类别选项接口。

结论：本次物料资料列表正本和分录物料选择态已按统一协议收口。BOM、委外等非弹窗物料查找点已登记，后续改为整列表选择时不得另起实现。
