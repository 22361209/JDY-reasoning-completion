# 验收报告 A101 库存预警

日期：2026-06-26

## 范围

- 审批范围：库存管理 / 库存预警，P1 第一版。
- 本批形态：非单据，安全库存阈值配置 + 库存预警查询列表。
- 机制参考：K3Cloud 物料库存属性中的安全库存/最高库存策略，查询层直查库存余额。

## 实现

- 后端新增 `inv_safety_stock_setting`，以 `product_id + warehouse_id` 唯一维护 `safety_qty` 和可选 `max_qty`。
- 新增 `/api/inventory/stock-alert-settings` 维护接口：读取、保存、删除安全库存阈值；写操作受 `inventory.stock_alert.manage` 权限保护。
- `/api/lists/stock-alert-list` 直查 `inv_stock_balance + inv_safety_stock_setting`，只返回低于安全库存或高于上限的商品仓库，不缓存查询结果。
- 前端新增 `frontend/src/modules/inventory/stock-alert/definition.ts`，库存管理菜单出现“库存预警查询表”。
- `DataListPage` 增加库存预警列定义和“安全库存设置”弹窗，列表仍复用高密度筛选、表格、列设置、引出和分页范式。

## 关键断言

- `CP-118 / 成品仓` 当前可用量 `12`，最低安全量 `20`，预警列表状态为 `低于安全库存`，预警差量 `8`。
- A101 专项脚本覆盖“低于安全库存出现在预警列表”、直查库存余额+配置、前端安全库存设置弹窗保存。
- 本批不走单据骨架，不新增审核、反审核、过账、红冲逻辑；未改财务、税务、编号。
