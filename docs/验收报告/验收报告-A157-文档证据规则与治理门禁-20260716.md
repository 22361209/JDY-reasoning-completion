# 验收报告：A157 文档证据规则与治理门禁

## 验收范围

- 明确 ignored 运行产物、受版本控制验收报告、历史任务包和长期截图的保存边界。
- 新增一次可执行的文档治理检查，覆盖现行链接、当前任务/交接一致性、活动预算、顶层编号、历史方案标记与报告索引。
- 为 161 份既有验收报告建立简洁、可校验的目录索引；不改写报告正文。

## 通过项

- `scripts/docs-governance-check.mjs` 从仓库当前状态计算现行 Markdown 链接、任务包与快照 frontmatter、活动任务预算、顶层文档编号、两个历史方案标记及报告文件名清单 hash；任一不一致均 fail-closed。
- 活动任务缺预算、缺停止条件、缺 JDY 参考声明、坐标不同步、报告数量/hash 过期或现行链接失效时，均不能通过该检查。
- `docs/验收报告/README.md` 保存报告数量和文件名 hash，并优先链接 6E 关闭、A155、A156 与本报告；新增、删除或重命名报告必须同提交更新索引。
- `docs/guides/codex-execution-policy.md` 固化“ignored 运行产物不可单独构成交付证据、历史不批量改写、报告索引随变更更新、文档门禁不替代业务回归”的规则。

- 未执行业务、迁移、浏览器、后端、前端构建或 full 回归；文档门禁不替代它们。
- 未修改业务代码、数据库、生成物、交付状态、路线图或回归 manifest。
