# 验收报告：A49 操作日志默认只读预设

- 日期：2026-06-24
- 范围：系统设置 / 操作日志
- 目标：在 A45 后端共享预设基础上，补系统默认预设和只读保护，避免关键审计筛选条件被误删或覆盖。

## 完成内容

- 新增迁移 `V13__list_filter_preset_defaults.sql`，为 `sys_list_filter_preset` 增加 `is_default`、`read_only`。
- 新增迁移 `V14__operation_log_default_preset_status.sql`，修正默认预设状态口径为列表可见值 `成功`。
- 种子数据增加 `系统默认-红冲审计`。
- 预设列表接口返回 `isDefault`、`readOnly`。
- 后端拒绝覆盖同名只读预设。
- 后端拒绝删除只读预设。
- 前端打开操作日志后自动应用默认预设。
- 前端下拉显示 `默认` / `只读` 标记，并禁用只读预设删除按钮。
