# 验收报告 A114：生产计划与用料快照

- 范围：生产计划、生产任务、生产任务用料快照、生产领料依据。
- 结论：通过。生产链已从“标准 BOM → 生产任务 → 领料”推进为“自发生产计划 → 生产任务 → 任务用料快照 → 领料/入库”的轻量三层。

## 变更

1. `docs/guides/business-rules.md` 明确业务三层方向：基础/标准层、任务/承诺层、执行结果层。
2. 新增 `production_plan`，生产任务创建时兼容旧接口并自动生成自发生产计划。
3. 新增 `production_task_material_snapshot`，生产任务创建时按当时 BOM 固化用料快照。
4. 生产领料改为读取任务用料快照，不再运行时直接读取 `prod_bom_line`。
5. 生产管理新增“生产计划”列表入口，生产任务列表显示计划号。
6. V58 将快照对 BOM 行的引用改为 `ON DELETE SET NULL`，标准 BOM 后续维护不会被历史快照阻断。

## 关键断言

`scripts/a114-production-plan-snapshot-regression.mjs`：

- 创建生产任务自动生成自发生产计划。
- 生产任务列表显示计划号。
- 创建任务后修改标准 BOM，再执行领料，领料数量仍按创建任务时的快照数量，而不是修改后的 BOM 数量。

本次样本：

- BOM：`BOM-A114-20260628015821`
- 生产任务：`SCRW-A114-20260628015821`
- 自发生产计划：`SCJH000011`
- 生产领料：`SOUT-A114-20260628015821`

## 边界

- 不把销售订单下推生产任务设为主路径。
- 不引入工序、派工、生产汇报、质检、MRP。
- 暂未改“同一生产任务重复领料”的历史兼容行为；后续可单独做剩余领料/超领控制批次。
