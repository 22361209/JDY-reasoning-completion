# 验收报告 A107 表格结构标准

日期：2026-06-26

## 范围

- 修复 A106 明细视图单据编号显示：明细行统一使用 `billNo`，并对 `bill_no` 做前端兜底归一。
- 共享 `DataListPage`：选择框列 + 序号列固定在最左侧，业务列不再继承旧 `fixed:left`。
- 共享 `EntryTable`：选择框列 + 序号列固定在最左侧；选择框表头改为全选复选框，无文字标题。
- 列表和表体统一增加细竖向列分界线。

## 关键实现

- `frontend/src/components/DataListPage.vue`
  - VXE 表格新增固定 `checkbox` + `seq` 两个系统列。
  - 列偏好恢复时清空业务列 `fixed`，避免旧偏好把业务列冻结到左侧。
  - 明细视图 `billNo` 渲染使用统一 `cellValue`，并归一兼容 `bill_no`。
- `frontend/src/components/EntryTable.vue`
  - 新增 `rowNo` 系统列。
  - `selection` / `rowNo` 强制可见、固定、不可配置、不可拖拽排序。
  - 表头选择列使用 `entry-select-all` 全选复选框。
- `frontend/src/styles/base.css`
  - VXE 列和表体列补 `1px` 竖向分界线。
  - 表体左两列使用 sticky 固定，第二列 left=44px。
  - 表体列筛选按钮绝对定位到表头右侧。
