## 正式事实与生命周期

V102 将收款/付款演进为“单据头 + 资金账户行 + 核销来源行”。保存要求头金额、资金合计和核销合计精确相等；所有金额用固定两位十进制字符串回传，version 也用规范十进制字符串保留 64 位精度。

- 保存草稿只写本单，不修改 `received_amount/paid_amount`，也不占用正式余量。
- 审核在 tenant 事务内锁头，并按稳定顺序 `FOR UPDATE` 所有 AR/AP 来源；同源竞争只有一张成功，后到者 409。
- 对已审核单据重复审核幂等，不重复增额或写第二条成功审核日志。
- 反审核按本单来源行精确释放金额并回 `DRAFT`；来源不一致时整单 409，不产生半截数据。
- 草稿修改使用 CAS，旧版本 409；草稿可删除，已审核单据不允许删除。
- 采购退货草稿保持对来源采购入库的共享锁，采购入库反审核使用同一 header 锁；并发时必定串行，不会留下指向已反审核入库单的退货草稿。
