# 验收报告：A50 操作日志预设按角色下发

- 日期：2026-06-24
- 范围：系统设置 / 操作日志、系统设置 / 用户角色
- 目标：在 A49 系统默认只读预设基础上，补角色维度下发能力，让不同岗位后续可以拥有不同默认审计视角。

## 完成内容

- 新增迁移 `V15__list_filter_preset_role_scope.sql`，为 `sys_list_filter_preset` 增加 `role_code`。
- 默认唯一约束从仅按 `list_key` 调整为 `list_key + role_code`。
- 现有 `系统默认-红冲审计` 预设挂到 `ADMIN`。
- session 接口返回当前用户 `roleCode`。
- 预设保存接口支持 `roleCode`。
- 预设列表接口只返回通用预设和当前角色预设。
- 前端预设下拉显示角色范围标记，例如 `ADMIN` 或 `通用`。
