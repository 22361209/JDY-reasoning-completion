# 验收报告 A19：源行号定位源单分录

- 日期：2026-06-24
- 批次：A19 源单追踪定位到源单具体分录
- 范围：销售出库追踪销售订单、采购入库追踪采购订单
- 目标：下游单据不只打开源单单头，还能根据分录源行号定位到源单具体分录行。

## 本次实现

- 销售出库、采购入库分录中的源行号改为可点击入口。
- 点击 `#N` 后打开对应源销售订单/采购订单，并定位到源单第 `N` 行。
- 源单目标分录行增加高亮底色和左侧提示线。
- 顶部提示显示已定位的源行号。
- 表头 `追踪源单` 继续可用；若当前单据存在源行号，则优先定位第一条带源行号的分录。
