- 日期：2026-06-26
- 范围：销售订单、销售出库草稿分录单价回填；商品主数据默认销售价；后端销售价格查询。

## 实现

- 后端新增 `GET /api/sales-prices/unit-price`，按客户+商品查询最近一次已审核销售订单/销售出库分录 `unit_price`，无成交记录时回退商品 `default_sale_price`，再无则返回 0。
- 商品主数据新增可选“默认销售价”，列表、增改接口和 Flyway 迁移同步支持。
- 销售订单选客户/换客户时重算当前已填商品行单价；选商品时按当前客户回填该行单价。
- 销售出库手工行同样支持选客户/选商品回填；源单下推行保留源单单价，不被价格记忆覆盖。
- A94 口径保持不变：回填字段为 `unitPrice`，价税合计继续由现有税率和含税口径推导。
