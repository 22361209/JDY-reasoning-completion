# 验收报告：A67 跨标签登录态失效同步

- 日期：2026-06-24
- 批次：A67
- 范围：前端正式登录态、跨标签退出同步、会话失效提示
- 结论：通过

## 本批目标

正式登录上线后，同一浏览器多标签页会共享后端 session。若其中一个标签页退出、改密或会话过期，其他标签页不能继续停留在“已登录”的假状态。本批补跨标签登录态失效同步和聚焦时会话校验。

## 实现内容

- 退出、改密、受保护 API 401 过期统一走本地会话清理。
- 会话清理通过 `localStorage` 广播失效事件，其他标签页收到后立即回到登录页。
- 标签页重新获得焦点时会重新请求 `/api/system/session`，若后端 session 已失效则清理本地登录态。
- 跨标签退出后保留可见提示，避免员工误以为还能继续操作。
