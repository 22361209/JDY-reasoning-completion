# 验收报告-A17-分录 Excel 多行粘贴

- 日期：2026-06-24
- 批次：A17 分录 Excel 多行粘贴
- 范围：销售订单分录录入效率
- 结论：通过

## 本批完成

1. 分录的商品编码、仓库、数量、单价输入框支持粘贴多行表格文本。
2. 支持 Excel 常见 TSV，也兼容逗号/分号分隔。
3. 粘贴格式为：`商品编码 / 仓库 / 数量 / 单价`。
4. 从当前行开始覆盖并自动扩展分录行，粘贴后自动刷新行金额和合计。
5. 保存草稿后，后端详情能读回相同三行分录。

## Playwright 断言

| 场景 | 断言 |

| 金额与合计 | 行金额为 `172.00 / 282.00 / 48.00`，合计 `502.00` |
| 保存草稿 | 单据 `XSDD-20260624-153701780-UQE` 保存成功；后端详情读回三行与粘贴内容一致 |
