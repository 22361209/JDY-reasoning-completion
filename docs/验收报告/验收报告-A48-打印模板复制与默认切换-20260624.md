# 验收报告：A48 打印模板复制与默认切换

- 日期：2026-06-24
- 范围：系统设置 / 打印模板
- 目标：在 A47 默认模板维护基础上，补同一单据多模板、模板副本和默认模板切换，让打印输出按当前默认模板生效。

## 完成内容

- 打印模板页新增 `另存为副本`。
- 同一单据可保留多个启用模板。
- 右侧新增 `当前模板` 下拉，可在同一单据的多个模板之间切换。
- 新增 `默认模板` 开关。
- 后端模板列表接口改为返回全部启用模板。
- 保存默认模板时，同一单据其他模板自动降为非默认。
- HTML/PDF 输出继续按当前默认模板读取。
