## Writer、主体与状态

- 认证拦截器通过后，`OperationActorProvider` 使用 session username 查询 `public.sys_user`，并缓存 request-time USER UUID/username/display snapshot；请求体中的 ownerName/userName 不能成为 actor。
- `OperationLogCommand` 显式声明 module、action、target、actor mode、outcome、reason 和状态白名单；scope 由 `logCurrent/logPlatform/logTenant`、`TenantContext` 与显式 `TenantTarget` 决定。
- USER 的 `operated_by` 必须非空；SYSTEM/ANONYMOUS 必须为空；生产 writer 不暴露 HISTORICAL_UNKNOWN 创建入口。
- 状态只允许受控 scalar/集合字段，UTF-8 JSON 上限 8 KiB；密码、hash、token、contact、webhook secret、附件和完整请求体不进入日志。
- 通用 WRITE_DENIED/WRITE_FAILED fallback 仅记录 HTTP method + Spring route pattern，不读取真实 URI 或 path variable，不推断业务对象身份。
- request marker 与 typed failure key 共同去重；失败日志使用独立事务，不随业务回滚丢失。
- 生产源码除共享 writer 外原始 `INSERT sys_operation_log` 为 0，旧 primitive `operationLogService.log(...)` 调用为 0。
