## 完成项

1. 表体源单拆列：`EntryTable` 将源单号、源单行号拆成两列，销售出库、采购入库等有源单分录的单据统一生效。
2. 选择器大模态：`MasterSelectorDialog` 放大为大模态，保留左侧分类、搜索、完整表格、选择态和确定/取消。
3. 销售出库选源单：入口移到单据工具栏，与新增/保存/审核同一行；删除表头追加源订单输入框、追加明细和表头追溯按钮；大弹窗内保留搜索、全选、列设置和横向滚动。
4. 表体手感：`EntryTable` 表头对齐 `DataListPage`，支持列宽拖动、列顺序拖拽 ghost、列过滤和列设置。
5. 列表批量反审核：`DataListPage` 对单据列表新增“反审核”按钮，仅选中已审核单据可用，调用现有 A95 `AUDITED -> DRAFT` 语义并受后端下游约束阻断。
6. 筛选图标：列筛选按钮改成简约小箭头，不再显示粗糙字符。
7. 选择器触发按钮：客户/供应商/商品/仓库触发按钮改为圆圈三点；表头常显，表体 hover/focus 显示。
