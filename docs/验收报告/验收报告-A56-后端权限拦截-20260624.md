# 验收报告 A56 后端权限拦截

- 日期：2026-06-24
- 批次：A56 后端统一权限拦截
- 范围：销售/采购/生产/财务/基础资料/打印模板/角色权限等高风险写接口

## 结论

PASS。后端已新增注解式权限守卫，带 `@RequirePermission` 的 `/api/**` 写接口会实时读取当前本地 `admin/ADMIN` 角色的 `sys_permission` 权限。临时移除权限后，直接调用后端 API 会返回 HTTP 403，目标业务方法不会执行；恢复权限后动作可继续成功。

| 类别 | 权限码 | 接口行为 |
| --- | --- | --- |
| 销售订单 | `sales.order.audit` | 审核/删除受控 |
| 销售出库 | `sales.out.audit` | 审核、反审核、作废、红冲受控 |
| 采购订单 | `purchase.order.audit` | 审核受控 |
| 采购入库 | `purchase.in.audit` | 审核、反审核、作废、红冲受控 |
| 生产 | `production.task.audit` / `production.document.audit` | 生产任务、领料、完工、反审核、红冲受控 |
| 财务 | `finance.settle` | 生成应收应付、收付款受控 |
| 基础资料/BOM | `master.data.manage` | 新增、编辑、禁用、删除、BOM 保存受控 |
| 打印模板 | `system.print_template.manage` | 保存打印模板受控 |
| 角色权限 | `system.role_permission.manage` | 保存角色权限受控 |

## 关键断言

- 临时移除 ADMIN 的 `sales.order.audit` 后，`POST /api/sales-orders/{billNo}/audit` 返回 403。
- 被拦截的销售订单仍保持 `DRAFT`，说明目标审核方法未执行。
- 临时移除 `system.print_template.manage` 后，`PUT /api/documents/sales-order/print-template` 返回 403。
- 临时移除 `master.data.manage` 后，`POST /api/master-data/product` 返回 403。
- 恢复原权限后，同一销售订单审核成功并返回 `AUDITED`。
