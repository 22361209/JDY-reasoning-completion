# 验收报告-A104-编辑锁

## 范围

- 后端新增单据编辑锁 `doc_edit_lock`，锁键为单据类型 + 单号，记录持锁用户、取锁时间和过期时间。
- 新增权限码 `document.lock.override`，管理员默认具备强制解锁/夺锁权限。
- 用户打开已有单据进入编辑时取锁；保存、关闭页签、释放接口会释放当前用户持有的锁；过期锁在取锁/查询时清理。
- 他人持锁时，打开同一单据进入只读模式；审核、编辑、保存、删除、下推、反审核、红冲等写动作禁用，前端提示“已被 X 打开，只读”。
- 高权限用户可点击“踢走并编辑”夺锁；原持锁用户后续写操作返回 423，并提示锁已被夺取、转只读。
- 删除 wave2 #10 旧列表锁 UX：列表不再标锁定行，不再弹“其他页签已打开”的旧提醒，编辑态完全由后端编辑锁决定。

## 变更摘要

- Flyway：`V48__document_edit_locks.sql` 建锁表并注册 `document.lock.override`。
- 后端：新增 `DocumentLockService`、`DocumentLockController`、`DocumentLockGuardInterceptor`，并接入权限 Web 配置和各草稿保存入口。
- 前端：打开已有单据时请求锁状态；表单按锁状态切换编辑/只读；只读态禁用写按钮；有 override 权限时显示夺锁按钮；关闭页签时释放锁。
- 回归：新增 A104 专项脚本，覆盖 B 打开被锁单只读、高权限踢走夺锁、保存/关闭释放锁；A91 回归改为断言旧列表锁 UX 已移除。
