# 验收报告：C 表单范式与主数据选择器

- 日期：2026-06-23
- 范围：销售订单、采购订单、主数据可搜索选择器、未保存关闭确认
- 结论：通过 A1 表单范式验收；采购订单仍是前端范式，未接后端保存

## 本次完成

- 销售订单和采购订单共用标准表单骨架：单头字段、分录表格、底部金额、未保存状态。
- 销售订单：客户、商品、仓库字段接入真实主数据可搜索选择器。
- 采购订单：供应商、商品、仓库字段接入真实主数据可搜索选择器。
- 商品选择后带出商品名称、规格型号。
- 表单字段变更会把当前页签标为未保存，关闭页签时弹出确认。
- 修复选择器异步串场：打开新选择器时清空旧候选，并用请求序号丢弃过期结果。

## 验收证据

- `frontend npm run build` 通过。

  - 商品选择后分录带出 `控制臂总成`。

- 采购订单尚未接入后端保存接口。
