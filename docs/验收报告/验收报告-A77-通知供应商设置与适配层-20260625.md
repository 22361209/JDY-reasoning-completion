# 验收报告：A77 通知供应商设置与适配层

- 日期：2026-06-25
- 批次：A77 通知供应商设置与适配层
- 范围：系统设置/通知供应商、系统设置/操作日志、通知 outbox、找回密码通知发送链
- 结论：通过

## 覆盖内容

- 新增 `system.notification_provider.manage` 权限和系统设置入口。
- 新增通知供应商设置 API，支持 `LOCAL / SIMULATED_HTTP / SIMULATED_SMTP`。
- 供应商设置持久化到 `sys_setting`，保存必须输入当前管理员密码。
- 保存供应商设置写入 `UPDATE_NOTIFICATION_PROVIDER_SETTING` 操作日志。
- 新增 `NotificationProviderService`，发送、重发、自动重试统一读取当前 provider code。
- 找回密码通知写入 outbox 时记录当前 provider，后续可替换为真实短信/邮箱适配器。
