# 验收报告 A116：生产计划采购申请第一段

- 日期：2026-06-29
- 范围：BOM 版本、生产计划新增/保存/下推、采购申请列表、采购订单采购申请占用后端口径。
- 结论：第一段通过。生产计划已能作为生产/采购任务统一入口，按母件当前 BOM 下推生产任务和采购申请；完整采购订单前端选源单、生产领料到产品入库前端串联仍留到下一段。

## 已完成

1. BOM 改为“一个母件一个当前可用 BOM + 历史版本”：
   - `prod_bom.version_no`
   - `prod_bom.is_current`
   - 当前母件唯一当前 BOM
   - 当前 BOM 编码唯一
   - 同母件版本号唯一
2. 生产计划：
   - 打开新增页由后端生成 `SCJH` 单号。
   - 分录以母件物料编码为主，自动带出当前 BOM、BOM 版本、物料名称、规格、单位、在制未完工数量。
   - 保存时写入 BOM 编码/版本快照。
   - 下推生成生产任务和采购申请。
3. 采购申请：
   - 新增 `purchase_requisition` / `purchase_requisition_line`。
   - 生产计划下推时按可采购子件默认供应商分组生成采购申请。
   - 采购申请列表可查看来源计划、供应商、物料、申请数量、已转订单数量、未转订单数量、交期、状态。
4. 采购订单后端：
   - 采购订单分录可记录采购申请来源单号和来源行号。
   - 重存采购订单时先释放本单旧采购申请占用，再按新分录重记。
