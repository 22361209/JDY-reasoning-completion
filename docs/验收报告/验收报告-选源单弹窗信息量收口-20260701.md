# 选源单弹窗信息量收口验收报告

日期：2026-07-01

## 改动范围

- 统一改造共享 `SourceSelectorDialog`，不在单据页面新增私有弹窗。
- 选源单弹窗扩大为接近工作区尺寸，并把滚动收敛到表体区域。
- 选源单弹窗默认具备关键字搜索框、列设置按钮和底部汇总栏。
- 依赖单头客户/供应商的选源单入口先做前置校验，未选往来单位时只在单据页提示，不打开空弹窗。
- 销售订单、发货通知、销售出库、采购订单、采购入库、采购退货、委外源单选择均接入底部业务汇总。

## 验收标准

- 打开任一选源单弹窗，弹窗宽高足以承载明细表，表体可横向和纵向滚动。
- 弹窗顶部保留关键字搜索框，搜索后只展示命中的源单明细行。
- 关键字输入后不即时过滤，必须回车或点击查询按钮后才执行过滤。
- 输入关键字但不查询时关闭弹窗，再次打开不得残留未提交关键字。
- 弹窗顶部存在列设置按钮，可隐藏和恢复列。
- 列设置的隐藏、固定左/右、恢复默认必须在普通数组列配置页面同样生效，不允许只支持响应式列配置页面。
- 弹窗底部显示当前明细行数、已选行数和业务数量汇总。
- 底部“已选/已选数量”必须按完整候选集统计；即使已选行被当前关键字过滤隐藏，统计也必须与最终确认追加结果一致。
- 选源单弹窗仍复用共享 `SourceSelectorDialog`、`TableCore`、`ColumnSettingsDialog`，不得在单据页面重新实现弹窗表格。
- 未选择客户/供应商时点击选源单，不打开 `SourceSelectorDialog`，在单据页消息区提示先选择往来单位。

## 验收结果

- `npm run build` 通过。
- `node scripts/a102-core-flow-ui-regression.mjs` 通过。
- A102 浏览器回归实测销售出库选源单弹窗尺寸为 `1334 x 720`，表体横向滚动可用，底部汇总显示当前明细和剩余可出合计。
- 发货通知单实测：未选客户点击选源单提示“请先在单头选择客户”，且 `SourceSelectorDialog` 未打开；选客户后输入销售订单号不即时过滤，点击查询后展示命中明细；表体 `overflow-x` / `overflow-y` 均为 `auto`。
- 发货通知单实测列设置：隐藏“单价”后表头消失；将“销售订单”固定左侧后表头 `position: sticky`、`left: 0px`；恢复默认后“单价”恢复且“销售订单”不再 sticky。
- 销售出库单实测：输入未提交关键字后取消并重开，搜索框为空；选中 2 行发货通知明细后再查询到 0 行，底部仍显示 `已选：2 行`、`已选数量：5`，确认后追加 2 行源单明细。
- `git diff --check` 通过。

## 残余说明

- 搜索仍沿用当前前端内存过滤模式，未改后端接口。
- 列设置仍沿用现有列设置弹窗能力，未引入新弹窗系统。
