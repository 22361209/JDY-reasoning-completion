# 选源单弹窗信息量收口验收报告

日期：2026-07-01

## 改动范围

- 统一改造共享 `SourceSelectorDialog`，不在单据页面新增私有弹窗。
- 选源单弹窗扩大为接近工作区尺寸，并把滚动收敛到表体区域。
- 选源单弹窗默认具备关键字搜索框、列设置按钮和底部汇总栏。
- 依赖单头客户/供应商的选源单入口先做前置校验，未选往来单位时只在单据页提示，不打开空弹窗。
- 销售订单、发货通知、销售出库、采购订单、采购入库、采购退货、委外源单选择均接入底部业务汇总。
- 选择列列头不再显示文案；支持批量选择的弹窗在选择列列头放置全选框。
- 选源单弹窗底部增加分页区域和每页条数选择，作为共享弹窗协议的一部分。
- 选源单弹窗默认展示行备注列，并支持关键字命中行备注。
- 选源单弹窗表格完整接入共享 `TableCoreHeaderCell` 与 `ColumnFilterPopover`，滚动条、列筛选、列宽调整统一复用列表页协议。
- 选源单查询统一接入 `ListQueryService`，由 `SourceSelectorListQueryAdapter` 承载各单据候选源单 SQL。
- `fetchSourceSelectorRows` 按统一查询协议拉齐当前过滤全集，弹窗本地分页只影响展示，不改变全选语义。
- 共享弹窗的列头复选框语义明确为：勾选选择当前过滤结果全部候选行，取消清空全部已选行。

## 验收标准

- 打开任一选源单弹窗，弹窗宽高足以承载明细表，表体可横向和纵向滚动。
- 弹窗顶部保留关键字搜索框，搜索后只展示命中的源单明细行。
- 关键字输入后不即时过滤，必须回车或点击查询按钮后才执行过滤。
- 中文输入法组合输入期间按回车只提交候选字词，不得触发选源单查询。
- 输入关键字但不查询时关闭弹窗，再次打开不得残留未提交关键字。
- 弹窗顶部存在列设置按钮，可隐藏和恢复列。
- 列设置的隐藏、固定左/右、恢复默认必须在普通数组列配置页面同样生效，不允许只支持响应式列配置页面。
- 弹窗底部显示当前明细行数、已选行数和业务数量汇总。
- 选择列列头不得显示“选择”等文案；可全选页面使用列头全选框，不再在工具栏额外放“全选”按钮。
- 清空当前可见选择通过同一个列头全选框完成：先全选，再取消全选后，已选行数和已选数量必须归零。
- 底部“已选/已选数量”必须按完整候选集统计；即使已选行被当前关键字过滤隐藏，统计也必须与最终确认追加结果一致。
- 弹窗底部必须保留分页区域，默认显示总条数、每页条数、上一页、当前页/总页数、下一页；当前未接后端分页时也要由共享弹窗稳定处理当前页切片。
- 所有选源单弹窗必须默认展示行备注列；行备注进入关键字搜索文本。
- 选源单弹窗除选择列外，所有可见列必须支持列筛选和列宽拖拽调整。
- 选源单弹窗外层不得再拥有独立横向滚动条；横向滚动必须统一由 `TableCore` 表格框承载。
- 选源单弹窗表体单元格必须复用列表页 `.vxe-cell` 内容结构，避免行背景和框线重复叠加。
- 选源单弹窗仍复用共享 `SourceSelectorDialog`、`TableCore`、`ColumnSettingsDialog`，不得在单据页面重新实现弹窗表格。
- 未选择客户/供应商时点击选源单，不打开 `SourceSelectorDialog`，在单据页消息区提示先选择往来单位。
- 选源单关键字、列筛选、日期、排序、分页必须走 `ListQueryService` 协议；页面不得直接调用私有源单候选接口。
- 底部“当前明细、剩余合计”等必须按统一查询返回后的最终可见行计算。

- 销售出库单实测：选择列列头文本为空，仅显示全选框；点击列头全选框后显示 `2 行已选`，再次点击后显示 `0 行已选`、`已选数量：0`。
- 销售出库单实测：底部分页区域显示 `共 2 条`、`第 1 / 1 页`，上一页和下一页处于单页禁用状态。
- 销售出库单实测：底部分页区域存在每页条数下拉，默认 `200条/页`，选源单表头默认展示“行备注”列，并可看到源单行备注内容。
- 销售出库单实测：关键字框处于中文输入法组合态时派发 Enter，不触发查询；组合结束后正常 Enter 才执行查询。
- 销售出库单实测：选源单外层 `.source-selector-table` 为 `overflow-x: hidden`，内部 `.table-core-frame` 为 `overflow-x: scroll`，横向滚动宽度大于视口宽度。
- 销售出库单实测：选源单“发货通知单”列宽可从 `150` 拖拽到 `230`，表头和表体同步变化。
- 销售出库单实测：使用“行备注”列筛选 `ONLY` 后，仅保留命中行，分页同步显示 `共 1 条`。
- 销售出库单实测：鼠标点击表头列分隔线附近可命中列宽热区，`cursor` 为 `col-resize`，列宽可从 `150` 拖拽到 `240`。
- 销售出库单实测：选源单表体不再使用背景横线渐变，`.vxe-table--body-wrapper` 的 `background-image` 为 `none`，每行只保留 `1px solid rgb(229, 235, 242)` 单元格底线。
- `git diff --check` 通过。
