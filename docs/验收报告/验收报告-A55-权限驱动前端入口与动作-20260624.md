# 验收报告：A55 权限驱动前端入口与动作

- 日期：2026-06-24
- 批次：A55
- 范围：当前 session 权限码、功能导航、快捷入口、列表按钮、表单审核、系统设置维护动作
- 结论：通过

## 本批完成

- `/api/system/session` 返回当前角色启用权限码。
- 前端 session store 增加 `roleCode`、`permissionCodes` 和 `hasPermission`。
- 功能导航和首页快捷入口按权限过滤。
- 表单审核按钮按单据类型权限禁用，并在调用前二次拦截。
- 列表批量审核、下推、主数据维护按钮按权限禁用。
- 打印模板保存/另存、权限矩阵保存按系统权限禁用，并在调用前二次拦截。
