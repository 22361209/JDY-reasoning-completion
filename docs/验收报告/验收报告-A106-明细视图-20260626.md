# 验收报告 A106 明细视图

- 日期：2026-06-26
- 范围：共享 `DataListPage`、列表 API `view=detail`、A106 专项与 A2-A106 全量回归。
- 对照：金蝶云星辰单据列表工具栏中的“整单”切换语义，按 `复刻-local` 已有历史单据列表证据对齐。

## 实现

- 所有可打开的单据列表默认保持整单视图，每行一张单据单头。
- 切到明细视图后，每行一条分录，统一带单据编号、单据日期、客户/供应商、审核状态、行号、商品编码、商品名称、规格型号、仓库、数量、单价、金额、源单号、源行号。
- 后端在 `/api/lists/{listKey}?view=detail` 直查单头 join 分录，覆盖销售订单、采购订单、销售出库、采购入库、生产领料、产品入库、其他入库、其他出库、调拨、盘点、盘盈、盘亏；查询只读，不做业务结果缓存。
- 明细视图复用列表列设置、列筛选、列宽拖动、分页、密度和引出参数，不为单据类型单独造页面。
