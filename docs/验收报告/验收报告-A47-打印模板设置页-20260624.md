# 验收报告：A47 打印模板设置页

- 日期：2026-06-24
- 批次：A47
- 范围：系统设置 / 打印模板
- 目标：在 A46 默认套打模板基础上补员工可用的设置入口，支持维护单据模板的公司抬头、模板名、页眉、页脚、签字栏和公司章区域。

## 实现内容

- 系统设置新增 `打印模板` 入口。
- 新增打印模板设置页，可按单据类型切换模板。
- 支持编辑模板名称、公司抬头、页眉说明、页脚说明。
- 支持开关签字栏和公司章区域。
- 后端新增模板列表读取接口和按单据类型保存接口。
- 保存后的模板会被 `print.html` 和 `print.pdf` 实际采用。
