# 验收报告：A46 单据 PDF 套打模板

- 日期：2026-06-24
- 批次：A46
- 范围：销售订单、采购订单、销售出库单、采购入库单、生产领料单、产品入库单
- 目标：在 A38-A40 的 PDF 输出基础上补默认套打模板配置，让单据 PDF 具备公司抬头、模板名、页脚说明、签字栏和公司章区域。

## 实现内容

- 新增 `sys_print_template` 表，按单据类型维护默认打印模板。
- 六类单据种入 `STANDARD / 标准套打模板`。
- 新增 `/api/documents/{documentType}/print-template`，可读取当前单据类型默认模板。
- `print.html` 和 `print.pdf` 均读取默认模板，并输出公司名、期间说明、模板名、页脚说明、签字栏和公司章区域。
- PDF 渲染改为多行结构，避免长备注、签字栏和页脚在右侧被裁切。
