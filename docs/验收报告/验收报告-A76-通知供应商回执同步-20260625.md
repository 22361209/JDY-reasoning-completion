# 验收报告：A76 通知供应商回执同步

- 日期：2026-06-25
- 批次：A76 通知供应商回执同步
- 范围：系统设置/用户角色、系统设置/操作日志、通知 outbox、本地供应商回执接缝
- 结论：通过

## 覆盖内容

- `sys_notification_outbox` 增加供应商回执状态和回执时间字段。
- 通知列表接口返回 `providerReceiptStatus`、`providerReceiptAt`。
- 新增管理员回执同步接口，支持本地模拟 `DELIVERED / FAILED / BOUNCED`。
- 用户维护页最近通知支持“回执成功 / 回执失败”操作和回执状态显示。
- 回执成功保持通知 `SENT`，回执失败转为 `FAILED` 并保留失败原因。
- 自动重试调度只处理未收到供应商回执的发送失败，避免覆盖供应商终态回执。
- 回执同步写入 `SYNC_NOTIFICATION_RECEIPT` 操作日志。
