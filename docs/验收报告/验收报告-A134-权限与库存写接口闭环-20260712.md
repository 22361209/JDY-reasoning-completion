## 完成的生产收口

### 1. 写接口 fail-closed 与具名 policy

- 新增固定权限、按单据动态权限、请求/资源动态权限、认证自助写和公开写五类访问语义。
- PUBLIC、AUTHENTICATED、preset 动态写不再共用一个宽泛 mode 注解，而是 3/3/2 个具名 policy；每个 policy 绑定唯一 HTTP method、路径和 handler。
- `WriteAccessPolicyContract` 在 Spring 启动期扫描真实 HandlerMapping；policy 缺失、复用、method/path 漂移或多映射都会阻止启动。
- Session 公共写边界直接复用同一 policy 注册表；公开 GET 继续使用方法 + 精确路径，不使用前缀放行。
- `PermissionGuardInterceptor` 对缺少或不匹配 `BEST_MATCHING_PATTERN` 的具名写 policy 返回 500，对未声明写接口返回 403。

### 2. 生命周期、单据锁与草稿权限

- 16 种 document type 映射到现有模块权限；低权限在进入生命周期服务前被拒绝。
- 单据锁 status/acquire 复用同一映射；release 只能释放当前 session 本人的锁，override 保留独立权限。
- 独立 review 找到 `productionTask` 曾在权限表中存在、却被锁服务自己的类型表遗漏；现已删除重复类型表，锁服务直接从唯一权限注册表派生支持集合。
- 真实 HTTP 复验：ADMIN 访问 `productionTask` 锁状态为 200，WAREHOUSE 为 403，未知 type 为 404。
- 11 个原先无保护的正式草稿保存入口复用现有模块 audit 权限；没有伪装成尚未设计的制审分离。

### 3. 员工、找回密码与 preset 边界

- `/api/system/users` 从匿名边界移除并要求 `system.role_permission.manage`：匿名 401、WAREHOUSE/FINANCE 403、ADMIN 200。
- 登录页删除员工 datalist、登录前用户列表请求和公共用户刷新；账号自由输入、缓存、账套选择、找回密码仍保留。
- 找回密码对存在和不存在账号返回完全相同的状态、结构与文案，不再返回 `matched`。
- PERSONAL preset 改用 immutable username + role 隔离，GET/保存/删除口径一致，不再使用可重复 display name。
- A49 使用一次性 ADMIN 探针账号验证角色默认，完成后精确清除账号、授权、角色和登录日志；A50 只删除自己的唯一 WAREHOUSE fixture，不再删除并回插整个角色 scope；A51 使用 username scope。
