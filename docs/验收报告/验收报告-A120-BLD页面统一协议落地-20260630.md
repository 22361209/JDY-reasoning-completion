## 当前允许例外

以下 raw table 暂不视为正式业务表体：

- `frontend/src/components/DocumentDialogs.vue`：零值确认、下游影响等二级提示表。
- `frontend/src/components/DataListPage.vue`：库存预警设置弹窗内轻量配置表。
- `frontend/src/app/App.vue`：打印/追溯 HTML 字符串里的输出表格。

后续如这些区域变成高频录入/筛选/配置页面，再迁入 `TableCore`。
