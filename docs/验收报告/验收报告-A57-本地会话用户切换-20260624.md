# 验收报告 A57 本地会话用户切换

- 日期：2026-06-24
- 批次：A57 本地会话用户切换
- 范围：本地用户种子、HTTP session、顶栏用户切换、前后端权限一致性

## 结论

PASS。系统已从固定 `admin` 权限判断升级为 HTTP session 驱动：`/api/system/session`、前端入口过滤和后端 `@RequirePermission` 均按当前会话用户角色权限生效。仓库员登录后前端销售订单入口隐藏，直接调用销售订单审核 API 返回 403；切回管理员后同一单据审核成功。

## 关键断言

- 浏览器切换到 `warehouse` 后，`/api/system/session` 返回 `username = warehouse`、`roleCode = WAREHOUSE`。
- `WAREHOUSE` 不含 `sales.order.audit` 权限。
- 仓库员会话下，销售管理模块仍显示销售出库入口，但销售订单入口隐藏。
- 仓库员会话直接调用 `POST /api/sales-orders/{billNo}/audit` 返回 403。
- 切回 `admin` 后，销售订单入口恢复，同一单据审核返回 `AUDITED`。
