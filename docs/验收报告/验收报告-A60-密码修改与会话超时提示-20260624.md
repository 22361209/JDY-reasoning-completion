# 验收报告-A60-密码修改与会话超时提示

日期：2026-06-24

## 范围

- 当前登录用户可在顶栏打开修改密码弹窗。
- 新增统一密码强度规则：至少 8 位，包含大写字母、小写字母、数字和符号。
- 管理员新增用户、重置密码和员工自助修改密码均使用同一密码规则。
- 修改密码需校验当前密码，修改成功后主动退出并要求重新登录。
- 服务端 session timeout 默认 30 分钟，可通过 `JDY_SESSION_TIMEOUT` 覆盖。
- 受保护 API 返回 401 时，前端自动回登录页并提示登录已过期。

## 断言结果

| 项目 | 结果 |
| --- | --- |
| 管理员弱密码重置 | 400 拒绝 |
| 员工弱密码自助修改 | 前端拦截 |
| 员工强密码自助修改 | 成功并退出 |
| 旧密码登录 | 失败 |
| 新密码登录 | 成功 |
| session 失效后访问受保护 API | 401，并回登录页 |

## 结论

通过。A60 补齐正式登录后的密码维护和会话失效体验，员工不再依赖管理员重置才能换密码；弱密码被前后端共同拦截，登录态过期会回到登录页而不是留在不可用页面。

## 备注

- 本批仍沿用本地 `{noop}` 密码存储模型，适配当前复刻阶段；后续正式生产化可切换为 BCrypt/Argon2 并加登录失败锁定。
