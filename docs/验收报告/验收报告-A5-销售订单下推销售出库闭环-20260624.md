# 验收报告 A5：销售订单下推销售出库闭环

- 日期：2026-06-24
- 范围：销售订单列表下推、销售订单详情接口、销售出库预填、保存、审核、源订单出库状态反写
- 结论：通过。已审核销售订单可以从列表下推生成销售出库单，并在审核后反写源订单为全部出库。

## 实现结果

1. 销售订单列表新增 `销售出库` 动作。
2. 只有单选、已审核、未全部出库的销售订单允许下推。
3. 后端新增 `GET /api/sales-orders/{billNo}`，返回客户编码、单头和明细。
4. 下推后自动打开销售出库单表单，生成新 `XSCK` 单号。
5. 销售出库单自动带入源订单号、客户编码、日期、部门、经办人、商品、仓库、数量和单价。
6. 销售出库单保存、审核成功后，源销售订单出库状态反写为 `全部出库`。

## 验收证据

- 前端：`cd frontend && npm run build` 通过。
- 后端：`cd backend && ./mvnw test` 通过。
- API：
  - `GET /api/sales-orders/XSDD-20260624-095543633-ZP0` 返回客户编码 `KH-001` 和明细 `CP-001 / CK-001 / 1 / 86`。
  - 销售出库审核后，销售订单列表返回 `outStatus = 全部出库`。
  - 销售出库列表返回 `XSCK-20260624-100200351-EQI`，状态 `已审核`，金额 `86.00`。
- Playwright：
  - 从销售订单列表选中 `XSDD-20260624-095543633-ZP0`。
  - 点击 `销售出库` 下推生成 `XSCK-20260624-100200351-EQI`。
  - 点击 `保存`、`审核` 后页面显示 `已审核` 和 `审核成功`。
  - 截图：`verification/playwright/a5-sales-order-push-sales-out-1366.png`。
