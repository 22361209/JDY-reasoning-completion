- ADMIN 默认拥有全部启用权限，WAREHOUSE/FINANCE 写入岗位默认权限。
- 新增 `/api/system/role-permissions` 和 `/api/system/roles/{roleCode}/permissions`。
- 系统设置新增“权限矩阵”页，支持按角色勾选权限并保存。
- `/api/system/session` 从 `sys_user/sys_user_role/sys_role` 读取当前 admin 账号和角色。
