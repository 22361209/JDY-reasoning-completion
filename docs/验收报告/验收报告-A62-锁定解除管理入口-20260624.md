# 验收报告-A62-锁定解除管理入口

日期：2026-06-24

## 范围

- 用户维护列表返回失败登录次数、锁定状态、锁定到期时间和最近登录时间。
- 系统设置/用户角色中显示账号安全状态。
- 管理员可对已锁定账号执行解除锁定。
- 解锁后清零失败次数、清空锁定到期时间，并允许员工重新登录。
- 解锁动作写入 `sys_operation_log`，可在操作日志中按用户名检索。

## 断言结果

| 项目 | 结果 |
| --- | --- |
| 新员工错误密码登录 5 次 | 账号进入锁定状态，用户角色页显示失败次数 5 |
| 管理员查看锁定账号 | 用户详情显示锁定状态和锁定到期时间 |
| 点击解除锁定 | 前端提示成功，失败次数变为 0，锁定状态变为未锁定 |
| 解锁后员工登录 | 使用正确密码可登录 |
| 操作日志按用户名查询 | 至少 1 条成功 `UNLOCK_USER` |

## 结论

通过。A62 把 A61 的登录锁定补成可管理闭环：员工被锁定后，管理员可以在用户角色页看见锁定原因性指标并解除锁定，系统同时保留操作日志证据。
