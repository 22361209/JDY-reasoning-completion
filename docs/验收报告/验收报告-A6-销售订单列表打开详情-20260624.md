# 验收报告 A6：销售订单列表打开详情

- 日期：2026-06-24
- 范围：销售订单列表单据编号点击、后端详情读取、销售订单表单回填
- 结论：通过。销售订单列表已具备员工日常使用所需的“列表打开单据详情”路径。

## 实现结果

1. 销售订单列表的 `单据编号` 列改为可点击入口。
2. 点击单据编号后读取 `GET /api/sales-orders/{billNo}`。
3. 销售订单表单回填真实后端单头和明细。
4. 后端状态映射到前端表单状态，已审核单据打开后显示 `已审核`。
5. 打开已有单据不标记为未保存，保存/审核/删除按已审核状态置灰。
