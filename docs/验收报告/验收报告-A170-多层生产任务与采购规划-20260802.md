# 验收报告：A170 多层生产任务与采购规划

## 结论

A170 已把生产计划下推扩展为逐行可控的多层生产与采购规划：每条计划分录可独立选择是否递归生成自制子件生产任务、是否为展开范围内的非自制件生成采购申请。采购申请已重构为可维护草稿，支持默认供应商、删行、改数量和补录供应商；审核后按供应商拆分生成独立采购计划单。

本批不把采购计划偷换为采购订单，也不改变生产领料和产品入库读取任务冻结用料快照的边界。F031、F032 以用户本次明确批准进入 `verified/published/A3`；新采购服务尚未补齐成功操作日志，所以不提升到 A4。

## 实现范围

- 生产计划分录新增“多层生产任务”和“生成采购申请”开关，保存后作为计划快照返回；已审核计划按每行选择组合下推。
- 自制子件递归解析当前已审核、启用 BOM，生成带计划行、来源 BOM、来源 BOM 行、层级、父任务和冻结用料的独立生产任务；循环、深度或节点超限在写入前整批阻断。
- 非自制叶子按计划行采购开关汇总到一张采购申请，保留来源任务、BOM、层级、仓库、交期和数量快照。
- 采购申请草稿可删行、改申请数量、使用共享供应商联想/完整选择器补录供应商；默认供应商从物料资料带出，无供应商仍可保存和审核，但下推必须阻断并指出具体行及物料。
- 已审核采购申请按行供应商分组生成多张采购计划，使用独立 `CGJH` 编号和来源占用；采购计划只有列表、只读详情与审核/反审核，不提供手工新增或修改。
- V111 新增计划开关、生产任务来源树和快照、采购申请行供应商/计划占用以及采购计划表，并同步 public、既有 tenant 和未来 tenant 的 89 表拓扑。

## 实际链路证据

### 自动业务链路

- 生产计划 `SCJH000148` 包含三个型号，分别组合“多层+采购”“仅采购”“仅根任务”。
- 下推生成根任务与递归子任务 `SCRW000712`–`SCRW000715`，数量、父任务、来源层级和 BOM 行快照均与三级 BOM 一致；未选择多层的计划行只生成根任务。
- 同次下推生成采购申请 `CGSQ000187`；默认供应商行带出 `GYS-001`，缺供应商行在下推时被阻断，补录 `GYS-002` 后按供应商生成 `CGJH000003`、`CGJH000004`。
- 已进入采购计划的申请行不再作为采购订单直接选源；采购详情接口对无权限角色返回 403，跨账套数据通过 tenant 路由隔离。

### 真实页面

- 隔离前端 `http://127.0.0.1:15173/` 连接当前 A170 后端 `18080`，生产计划 `SCJH000148` 的三条分录分别显示并冻结各自的两个开关组合。
- 交付运行时 `http://127.0.0.1:5173/` 已切换到同一 A170 前端并连接后端 `18080`；原工作区后端 `8080` 已恢复，不与本批运行时串用。
- 采购申请草稿 `CGSQ000188` 实测申请数量可从 10 改为 12，供应商输入 `GYS` 会返回 `GYS-001`、`GYS-002` 等候选，删除按钮可移除整行；验收编辑随后选择“不保存”，数据库未被改写。
- 已审核申请 `CGSQ000187` 显示两条不同供应商明细；采购计划列表显示同一申请拆成两张计划，`CGJH000003` 详情只包含 `GYS-001` 和对应物料，页面仅有审核/反审核动作。
- 浏览器控制台只有 Vite 连接调试日志，无 error 或 warning。

## 保留边界

- A170 不做库存净需求、提前期、安全库存、批量策略、产能排程或完整 MRP。
- A170 只到采购计划，不自动生成采购订单、采购入库、应付或库存事实。
- 成功操作日志仍是采购申请/采购计划从 A3 提升 A4 的明确缺口；失败写操作继续由统一异常日志记录。
- A2–A7、A40、A46、A53 的生产入库夹具需单独按 A167 母件约束修订；本批只记录，不回填历史脚本。
- 原 `main` 工作区 A166 未提交改动不属于本批；本批不 push。
