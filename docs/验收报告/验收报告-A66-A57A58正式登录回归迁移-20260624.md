# 验收报告：A66 A57/A58 正式登录回归迁移

- 日期：2026-06-24
- 批次：A66
- 范围：A57 会话权限回归脚本、A58 用户维护回归脚本
- 结论：通过

## 本批目标

A59 已经用正式登录页替代开发期顶栏用户切换器，但 A57/A58 历史回归脚本仍在查找 `session-user-select`、`session-switch`。本批把两条关键权限/用户维护回归迁移到正式登录/退出流程，避免测试依赖退役入口。

## 实现内容

- A57 改为管理员正式登录创建销售订单草稿，再退出并登录仓库员验证菜单过滤和后端 403，最后重新登录管理员完成审核。
- A58 改为管理员正式登录创建员工，退出后用员工初始密码登录验证无权维护用户，再由管理员重置密码，最后员工用新密码登录。
- 两条脚本结果增加 `loginFlow: "formal-login"`，显式说明已迁移到正式登录流。
