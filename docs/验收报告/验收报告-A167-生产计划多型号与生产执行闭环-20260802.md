A167 已把生产计划母件从游离文本改为物料主数据稳定主键，并让一张生产计划可保存、审核和下推多个型号。每条计划明细独立生成生产任务，后续生产领料、产品入库、库存流水和任务进度均可追溯到对应任务与计划明细；隔离端口的真实页面和后端回归均已跑通。

## 实现范围

- 新增 `production_plan_line`，保存母件 `product_id`、编码/名称/规格/单位、BOM、仓库、车间、计划数量和交期快照；历史单行计划迁移为首条明细。
- `production_task.plan_line_id` 和采购申请来源明细建立稳定追溯；计划审核后按有效明细逐行下推，重复下推被阻止。
- 生产计划页面支持物料选择、增行、插行、删行、列表回开与审核后只读；一张计划可包含多个不同型号。
- 生产领料按任务 BOM 快照生成并以“可生产套数”回写已领数量；审核后扣减原料库存。
- 产品入库支持生产任务选源，也支持从已审核领料单下推；校验母件一致性、可完工数量和来源领料，审核后增加成品库存并回写完工数量。
- 下游已存在时阻止反审核/删除上游单据；补齐统一锁顺序，避免领料、入库并发保存时锁顺序分叉。
- V110 同步覆盖 public 与 tenant schema，并更新新账套初始化、拓扑约束回归和 regression manifest。
