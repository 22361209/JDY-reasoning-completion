# B1 高密度列表范式验收报告

## 基本信息

- 验收日期：2026-06-23
- 验收范围：VXE Table 接入、通用列表组件、6 个样板列表、列表 stub API、列设置、列过滤、列宽拖动、表头拖拽换列、状态态、列偏好持久化、1000 行验证、回车查询、勾选、批量确认、同单据锁定
- 测试账号：本地 stub 用户 `本地管理员 / 系统管理员`
- 验收结论：B1 列表范式已可用，空态/错误态/无权限态、列偏好持久化、列表 API 契约和 1000 行验证已补齐
- 等级说明：达到 A1 列表可操作；不是 A2/A3 业务闭环，真实保存/审核/库存回写尚未进入本批

## 通过项

- 已接入 `vxe-table` 和 `xe-utils`，并在 Vue 入口全局注册。
- 新增通用列表组件 `frontend/src/components/DataListPage.vue`，承载筛选、工具栏、VXE 表格、分页、列设置、批量动作确认。
- 新增列表 API service `frontend/src/services/listApi.ts`，可区分成功、无权限、错误和网络异常。
- 新增后端 stub API `GET /api/lists/{listKey}`，统一返回 `page/pageSize/total/sortField/sortOrder/rows`，支持 `keyword/status/page/pageSize/sortField/sortOrder/columnFilters`。
- 新增列表 API 契约文档 `docs/13-列表API契约.md`。
- 已落 6 个样板列表：`商品资料`、`客户`、`供应商`、`销售订单列表`、`采购入库单`、`库存查询`。
- 列设置入口已可用，支持列显隐和固定方向选择。
- 列设置支持按列表持久化列顺序、列宽、显隐、固定方向；本地键为 `jdy:list-columns:{listKey}`。
- VXE 表格已启用列宽鼠标拖动、固定列、横向表格结构、复选框列。
- 每列表头已提供靠右过滤按钮，浮层按金蝶样式提供 `包含/不包含/等于/不等于/以……开始/以……结束/为空/不为空` 操作符、输入框、重置和确定。
- 支持鼠标按住列标题任意空白/文字区域后拖拽到其它列左侧/右侧，实现列顺序调整；该交互独立于列宽拖动。
- 关键字搜索支持输入后按回车直接查询。
- 分页档位已调整为 `200/500/1000`，默认每页 `200` 条，避免用小样本档位误导高数据量业务。
- 仅列表页保留“刷新”，语义为按当前查询条件重新取数；表单壳层和功能导航中无实际逻辑的刷新按钮已移除。
- 左侧主导航已移除放大首字伪图标，仅保留模块名称，避免把文字误当作图标系统。
- 列表已支持加载态、空态、错误态、无权限态；空态已做浏览器截图验收，错误/无权限由接口状态驱动。
- `1000条/页` 已验证返回总数 `1200` 且渲染 `1000` 行，用于本地高数据量范式验收。
- 列表支持勾选、已选中数量、批量删除/审核确认弹窗。
- 销售订单列表在同一单据已打开时，审核/删除/批量操作锁定并提示。
- 库存查询页面文案明确：不做业务结果缓存，后续真实库存必须走数据库余额口径。
