# 验收报告：A45 操作日志后端共享预设

- 日期：2026-06-24
- 批次：A45
- 范围：系统设置 / 操作日志
- 目标：把 A44 的本机筛选条件预设升级为后端持久化共享预设，避免换浏览器或清空本机缓存后查不到常用审计条件。

## 实现内容

- 新增 `sys_list_filter_preset` 表，保存列表标识、预设名称、查询条件、列过滤条件、共享标记和更新时间。
- 新增 `/api/list-presets/{listKey}` 的读取、保存/覆盖、删除接口。
- 操作日志展开过滤区优先读取后端预设，保存和删除同步后端；后端不可用时保留本机降级保存。
- 预设内容覆盖关键字、状态、模块、动作、操作人、对象类型、起止日期和列过滤条件。
