## 边界

- 本批未新增业务功能，未改后端业务规则。
- 未重跑 `build-jdy-feature-approval.mjs`，未手改 `featureScope.ts`。
- FieldRenderer 当前只覆盖主数据详情页和旧建档弹窗；`DocumentForm` 表头字段和 `EntryTable` 分录单元格尚未迁入 FieldRenderer。
- `DataListPage.vue` 和 `EntryTable.vue` 仍不是最终极限拆分，但最容易膨胀的定义、偏好、选择、合计、列定义、计算和测试 ID 已经外移。

## 后续建议

- 下一步如继续收口，优先把 FieldRenderer 扩到 `DocumentForm` 表头字段。
- 再评估 `EntryTable` 单元格渲染是否要按字段类型拆出轻量 renderer；不要在没有明确收益前大拆分录编辑行为。
- 新增列表或单据时先复用 `ActionBar`、`DataListPage` / list composables、`StandardDocument`、`EntryTable`、`FieldRenderer`，再写业务 handler。
