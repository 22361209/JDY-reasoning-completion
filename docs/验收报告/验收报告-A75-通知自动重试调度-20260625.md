## 覆盖内容

- 启用 Spring scheduling。
- 新增 `NotificationRetryService`，默认每 5 秒扫描到期通知。
- 自动重试 `FAILED / PENDING` 且 `retry_count < 3` 的找回密码通知。
- 自动重试成功后状态回到 `SENT`，失败原因清空，重试次数递增。
- 自动重试动作写入 `AUTO_RETRY_NOTIFICATION` 操作日志。
