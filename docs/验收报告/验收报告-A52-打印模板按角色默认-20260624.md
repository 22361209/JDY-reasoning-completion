# 验收报告-A52-打印模板按角色默认

验收日期：2026-06-24  
结论：PASS

## 范围

本批在 A48 多模板与默认切换基础上，补打印模板角色默认：

- `sys_print_template` 增加 `role_code`。
- 默认唯一口径从 `document_type` 调整为 `document_type + role_code`。
- 当前 `ADMIN` 打印时优先使用 ADMIN 默认模板；无角色默认时回退通用默认。
- 设置页可选择作用范围：通用 / ADMIN。
- 模板下拉和左侧单据卡片显示模板作用范围。
