# 验收报告：A162 P0-2 采购订单—入库—退货发布闭环

## 结论

P0-2 的 F033 采购订单、F034 采购入库、F035 采购退货均达到 `verified / published / A3`。验证的是当前 ERP 的订单—入库—退货真实调用链；JDY 只作为既有术语与交互参考，未据此扩展采购功能。

## 直接证据

- 新增 `scripts/a162-purchase-publication-regression.mjs`，以唯一批次夹具执行采购订单审核、采购入库保存/审核、采购退货审核/反审核；验证入库审核前已收数量为 0、审核后为 2，退货反审核后退货可选源数量恢复为 2。
- 三类单据的草稿/审核写接口均核对真实权限。`finance` 用户对订单、入库、退货的保存草稿和审核请求均得到 403，响应准确指向对应权限；订单、入库、退货审核日志精确归属，退货日志包含 `AUDIT` 与 `REVERSE`。
- 已审核采购退货仍保留历史库存/应付影响时，采购入库反审核被生命周期规则以 409 拒绝；自动化明确验证这一受限动作，未将其误作可逆路径。
- `TenantPurchaseChainIsolationTest` 覆盖双 tenant 下订单—入库—退货的源单数量与库存追溯隔离；`FinanceSettlementAppServiceIntegrationTest` 和 `RedReverseTransactionIntegrationTest` 覆盖应付并发与红冲事务边界。
- 三张真实采购页面均完成 1440×900 和 390×844 浏览器取证。窄视口沿用列表页的水平滚动协议，验证页面及主要操作控件可见，不将其误报为移动端重排。
