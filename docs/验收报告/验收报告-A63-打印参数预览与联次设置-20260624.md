# 验收报告-A63-打印参数预览与联次设置

日期：2026-06-24

## 范围

- 打印模板增加纸张、横纵向、上/右/下/左边距和联次。
- 系统设置/打印模板页可维护上述参数，并在预览区显示。
- HTML 打印输出写入 `@page` 纸张方向和边距，并显示联次。
- PDF 打印输出按纸张方向设置 `MediaBox`，按联次生成多页。
