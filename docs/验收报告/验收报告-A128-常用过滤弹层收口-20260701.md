# A128 常用过滤弹层收口验收报告

日期：2026-07-01

## 项目边界

本次只处理列表查询栏的常用日期过滤和日期范围弹层：

- 常用过滤条件补充 `上季度`。
- 舍弃 `ListQueryBar` 私有的 `date-filter-menu` / `date-range-popover` 弹层体系。
- 弹层打开不得改变查询栏布局，日期范围按钮不得发生横向位移。

不调整后端查询协议、不调整销售订单整单/明细语义、不调整列头筛选规则。

## 对齐标准

- `docs/guides/list-query-unification-protocol.md`：常用过滤条件和日期范围都必须落到 `dateFrom/dateTo`，查询栏按钮必须与同区按钮共享视觉规则。
- `docs/guides/bld-page-unification-protocol.md`：新增页面交互不得重新发明筛选/弹层视觉体系，应复用已有按钮、筛选和弹层组件。
- `docs/10-前端体验与视觉规范.md`：高密度列表按钮位置必须稳定，弹层打开不能引发布局跳动。

## 落地内容

- `ListQueryBar` 增加 `previousQuarter / 上季度`，计算上一季度起止日期；2026-07-01 场景下为 `2026-04-01 至 2026-06-30`。
- `ListQueryBar` 弹层改用 `.column-filter-popover`、`.filter-operator-list`、`.column-filter-actions` 视觉体系。
- `ListQueryBar` 的 `expanded` 只由外部展开过滤状态决定，不再受 `quickDateMenuOpen/dateRangeOpen` 影响。
- 删除 `base.css` 中私有 `.date-filter-menu`、`.date-range-popover`、`.date-range-actions` 样式。
- A128 静态扫描新增：
  - 协议必须登记 `上季度`。
  - 查询栏不得引用私有 date-filter 弹层 class。
  - CSS 不得保留私有 date-filter 弹层样式。
  - 查询栏弹层必须复用 `column-filter-popover`。
- A128 浏览器回归新增：
  - 常用过滤条件包含 `上季度`。
  - 上季度写入正确 `dateFrom/dateTo`。
  - 打开常用过滤条件时，日期范围按钮横坐标不变。

## 验收标准

- `常用过滤条件` 菜单显示 `本月 / 上月 / 本季度 / 上季度 / 本年度 / 上年度`。
- 点击 `上季度` 后，当前日期为 2026-07-01 时显示 `2026-04-01 至 2026-06-30`。
- 打开 `常用过滤条件` 菜单前后，`日期范围` 按钮位置不横向跳动。
- `ListQueryBar` 不再使用 `date-filter-menu` 和 `date-range-popover` class。
- `base.css` 不再保留 `.date-filter-menu` 和 `.date-range-popover` 样式定义。
- A128 静态扫描、A128 浏览器回归、前端构建通过。
