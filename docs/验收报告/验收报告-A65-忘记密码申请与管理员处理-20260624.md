# 验收报告：A65 忘记密码申请与管理员处理

- 日期：2026-06-24
- 批次：A65
- 范围：登录页忘记密码申请、管理员用户维护页处理、密码重置与审计
- 结论：通过

## 本批目标

正式登录已可用后，员工忘记密码缺少可走通的外部入口。本批不伪造短信/邮箱网关，先建立可长期接入外部通道的正式闭环：员工在登录页提交找回申请，管理员在系统设置/用户角色页核验并重置密码，申请状态和操作日志留痕。

## 实现内容

- 新增 `sys_password_reset_request` 表，保存找回申请、处理状态、处理人和处理备注。
- 登录页增加“忘记密码”入口，未登录状态可提交账号和联系方式/说明。
- 管理员用户维护页显示待处理找回申请，可选中对应员工，重置密码后自动标记申请完成。
- 管理员可驳回申请，处理动作进入操作日志。
- 重置密码时同步清空失败次数和锁定状态，避免员工刚重置仍被锁住。
