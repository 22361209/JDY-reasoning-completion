## 改动范围

- 在运行依赖中补齐 Redis starter，使既有 `spring.session.store-type: redis` 真正生成 Redis `SESSION`；Surefire 进程单独排除 Session 自动配置，保留现有 MockMvc `MockHttpSession` 测试语义，不改变生产会话策略。
- 认证 helper 创建 run-unique ADMIN，核对 tenant、schema、角色和权限；只接受 Redis `SESSION`，精确记录并清理本轮 Redis 主 hash。调用者显式传入 Cookie 时，401 不再登录 ADMIN 重试。
- preflight 识别 A140/A141/A142 的直接 SQL 角色/权限变更，并在每个 mutator 后重新核验角色矩阵与安全设置；主错误和 cleanup 错误分别保留。
- A44、A56、A162、A163 使用隔离 session；A56 清理测试销售订单；A162 分别聚合页面与浏览器关闭错误；所有成功 artifact 均在 cleanup 成功后落盘。
- Java tenant 测试使用 run-unique ADMIN，在同一认证 session 内切换 tenant；销售、报价、订单、出库和报表日期统一从数据库当前日期推导上一月有效期间。
- 隔离身份删除前，必须跨 public 与所有获授权 tenant schema 精确删除并验证自身操作日志。若清理不完整，通用认证 helper 会保留身份并使门禁失败；Java tenant 夹具还会先禁用再保留，避免制造无主审计记录。
- 中央迁移 helper 固定 V105–V113 的脚本名与 Flyway checksum；A141/A142/A143/A146/A151 的 upgrade/fresh 历史复用该合同。A146 closure 同时验证两条调用路径及九项固定发布合同。
