# 验收报告-A59-正式登录与退出

日期：2026-06-24

## 范围

- 新增正式登录页，替代顶栏开发期用户切换器。
- 后端会话不再默认回退管理员；未登录访问受保护 `/api/**` 返回 401。
- 保留登录、退出、会话、登录候选用户和健康检查公开访问。
- 登录后继续按当前用户角色执行前端入口过滤和后端权限守卫。
