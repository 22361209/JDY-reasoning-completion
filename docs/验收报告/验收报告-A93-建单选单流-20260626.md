# 验收报告 A93：销售出库建单/选单流

## 范围

本批只重做销售出库建单/选单两条路径：

1. 销售订单审核后下推销售出库不再弹确认框，直接打开销售出库草稿，按剩余可出数量整行带入商品、仓库、数量、单价、行备注、交期和客户。
2. 销售出库直接建单支持手填源订单号拉入该订单剩余可出分录；也支持先选客户后，从该客户已下单销售订单明细中勾选同一订单的一行或多行拉入。

未改税务、编号、财务口径；未重跑 `build-jdy-feature-approval.mjs`；未手改生成物 `frontend/src/app/featureScope.ts`。
