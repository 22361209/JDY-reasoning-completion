## A140 固定技术边界

1. 员工和财务账户属于 tenant master-data；平台用户仍属于 system，tenant 表不得 FK 平台用户。
2. 两类主数据复用现有 registry、列表、记录页、字段渲染和 ActionBar，不另写 CRUD 页面。
3. V100 已同步 public、现有 tenant、新建 tenant 与备份恢复；受管表从 72 增至 74，约束数与拓扑由 A137 按真实 DDL 校验。
4. 新增、稀疏 PATCH、查看、审核、反审核、启停和选择器必须形成闭环；不开放删除。
5. 员工/账户维护使用 `master.data.manage`；财务只能读账户，仓库不能读两类；未知选择器 fail-closed。
6. 敏感日志不得记录手机号、邮箱或银行账号原值；员工关联、解除必须显式且可审计。撤销账套授权时必须原子释放该 grant 的员工关联并写原 tenant 审计，禁用 grant 不得继续占用员工唯一槽。
7. 员工关联请求的 `version` 只接受非负、64 位范围内的 JSON 整数；小数、高精度伪整数和越界值固定 400。
