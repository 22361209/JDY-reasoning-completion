## A141 已收口边界

1. F026 销售收款、F036 采购付款只打开或下推 finance 域同一套正式收款/付款能力，不在 sales/purchase 复制结算引擎。
2. 一张单据允许同一客户/供应商的多张应收/应付来源和多条资金账户行；不同往来单位不得混单。
3. 正式支持 CNY/USD；销售订单/采购订单明确选择，发货通知、销售出库和有来源采购入库逐级继承，无来源采购入库可选择。结算单头、全部来源、全部账户必须同币种，不做汇率、换算、汇兑损益或跨币种核销。
4. 草稿金额可为 0 且不需要原因，但不能为负数；审核总额必须大于 0。草稿零核销影响，重复审核幂等，反审核原子释放并回 DRAFT。
5. 旧立即结算记录必须无损保留；AUDITED legacy 头/明细只读且不可删除，但允许安全反审核，重新审核前必须补真实账户。两个旧“调用即结算”URL 退役为有权 410，匿名/无权仍先 401/403。
6. legacy 数据不得伪造资金账户、交易号或操作人；新正式单据不允许利用 legacy 例外绕过账户、币种或生命周期校验。
