# 任务包

## 目标

将文档治理中最容易重新漂移的约束变成一次可执行检查：当前任务/交接坐标、活动任务预算、现行 Markdown 链接、顶层文档命名、历史方案标记与验收报告索引。JDY 不作为本治理任务的需求或视觉参考。

## 明确不做

- 不修改业务代码、数据库、生成物、交付状态、路线图或回归 manifest。
- 不要求补写 161 份历史报告正文、旧截图或历史链接；只维护报告目录的索引完整性。
- 不把静态文档检查伪装成业务、浏览器、迁移或 full 回归。

## 验收

1. `node scripts/docs-governance-check.mjs` 在干净 checkout 直接运行，并对现行链接、任务/快照坐标、活动预算、顶层编号、历史方案状态和报告目录索引 fail-closed。
2. 新增或删除验收报告、损坏现行链接、任务包缺预算/停止条件、交接与任务坐标不一致时，检查返回失败。
3. 验收报告目录有数量和文件名 hash 索引，并指向当前优先阅读的关单与治理报告。
4. 新门禁、scope/status/manifest 三项静态门禁和 `git diff --check` 均通过；不运行 full。

验收结果见 `docs/验收报告/验收报告-A157-文档证据规则与治理门禁-20260716.md`。
