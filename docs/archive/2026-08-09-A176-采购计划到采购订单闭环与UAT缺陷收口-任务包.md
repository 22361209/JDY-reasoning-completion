# A176 任务包（已归档）

## 目标与范围

A176 将采购计划确立为采购订单的正式来源：已审核计划按供应商和剩余数量生成采购订单草稿，保存计划头/行、采购申请、价格和税率快照；订单审核占用计划已订数量，反审核释放占用，已有已审核采购入库时保持不可逆边界。采购入库、生产领料和产品入库继续使用既有库存、财务与 tenant 规则。

现场验收期间经用户确认纳入三项最小扩张：生产领料逐行保留任务快照仓库；下推已生成草稿但页签满载时显示单据编号和可恢复路径；UAT-DEF-001/002 分别收口密码错误提示和物料名称新建后返回选择。物料名称仍必须已审核、启用，不以草稿回填绕过后端守卫。

用户于 2026-08-09 将预算提高到 720 分钟、1,000 万 Goal tokens、8 个提交；子代理上限保持 0，full 上限保持一次。A167 临时库迁移回归阻断获准在本任务内修复测试夹具和当前版本期望，不修改既有迁移 checksum 或生产语义。
