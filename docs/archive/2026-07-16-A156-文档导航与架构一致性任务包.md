# 任务包

## 目标

把当前 ERP 的文档入口、架构说明和历史/现行边界收敛为可接手、可检索、不过度承诺的状态。JDY 只作为业务术语、交互和视觉参考；本任务不以像素级复刻作为验收目标。

## 明确不做

- 不修改业务代码、数据库、生成物、交付状态、路线图或回归 manifest。
- 不批量改写历史验收报告；历史失效链接通过现行入口、兼容说明或索引处理。
- 不将“正式多库 tenant 架构”误写成已完成；当前实现准确表述为共享应用、`public` 平台域与 schema-first tenant 路由。
- 不把 JDY 原始资料、截图目录或“95% 像素复刻”当作当前所有功能的硬门禁。

## 验收

1. 建立单一现行文档导航，能区分开工入口、架构/规则、运行手册、当前状态、历史证据和生成物。
2. `docs/00`、`docs/05`、多账套说明及验收规则不再与 ADR-011、A119、A137、ADR-015 矛盾。
3. 修复 ADR-010 中曾指向不存在文件的引用，并消除顶层 `12` 文件命名冲突。
4. 旧“新项目孵化”和 A115 元数据路线保留可追溯正文，但显式标为历史决策，不再作为当前默认路线。
5. 现行 Markdown 链接检查、scope/status/manifest 三项静态门禁和 `git diff --check` 均通过；不运行 full。

验收结果见 `docs/验收报告/验收报告-A156-文档导航与架构一致性-20260716.md`。
