## 目标

消除 A164 后 BOM 维护页剩余的外层纵向滚动，并保持子件表独立滚动。

JDY：不作为本批实现参考；只复用当前 ERP `form-layout` 的 flex 高度分配范式。

## 允许路径

- `frontend/src/modules/production/bom/BomForm.vue` 和 `frontend/src/components/BomEntryTable.vue` 的 BOM 专用布局。
- A165 的归档、验收报告、报告索引与交接快照。

## 明确不做

- 不改 BOM 业务逻辑、共享表格、后端 API 或其他入口。
- 不运行 full，不 push。

## 验收与结论

- BOM 外层改为受限 flex 工作区；基本信息和产品信息固定，子件区占剩余高度。
- 实测 `.content-area` 的 `clientHeight` 与 `scrollHeight` 均为 723px，外层不再纵向溢出；子件区与表体仍分别使用 `overflow: hidden` / `overflow-y: auto`。
- 前端构建通过，smoke 10/10 通过，文档治理检查通过；详见 `docs/验收报告/验收报告-A165-BOM页面工作区高度收口-20260720.md`。
