## Java 环境

项目脚本会自动使用 Homebrew OpenJDK 21，不要求把 Java 写进全局 shell 配置：

```bash
./scripts/backend-test.sh
./scripts/dev-up.sh
```

脚本入口：

- `scripts/java-env.sh`：统一解析并导出项目级 `JAVA_HOME/PATH`。
- `scripts/backend-test.sh`：后端测试统一入口，默认执行 `backend/mvnw test`。
- `scripts/dev-up.sh`：启动后端时复用同一套项目级 Java 规则。

验证本机 JDK：

```bash
JDY_JAVA_HOME="/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home" ./scripts/backend-test.sh -version
```

如需临时覆盖项目默认 JDK，可设置 `JDY_JAVA_HOME=/path/to/jdk`，不建议改系统全局环境。

## 后端

运行：

```bash
cd "/Users/linzhenyue/Projects/JDY 推理补完"
./scripts/dev-up.sh
```

健康检查：

```bash
curl http://127.0.0.1:8080/api/system/health
curl http://127.0.0.1:8080/actuator/health
```

说明：

- 后端使用 Spring Boot 3.5.15、Java 21、Maven Wrapper。
- 第一版 Redis 用于登录态/会话和平台级密码找回限流，不缓存库存、单据、资金等业务结果。
- Flyway 会自动执行 `backend/src/main/resources/db/migration` 下的迁移。
- `scripts/dev-up.sh` 是本地回归入口，会显式使用 `local` profile，并且只为 `BLD-TEST` 开启受控库存造数能力。启动前脚本对当前 workspace 路径及 backend 构建输入计算确定性 fingerprint，通过 `JDY_DEV_BUILD_FINGERPRINT` 注入后由 `/api/system/health` 的 `devBuildFingerprint` 回传。复用 8080 时 fingerprint 必须与当前工作区及源码完全一致，且 `testInventoryAdjustmentApi` 必须为 `true`；默认或外部启动的 fingerprint 为空，旧构建、跨工作区进程和生产式配置都会被拒绝复用。
- 复用 5173 时，脚本会通过监听进程的 cwd 核对它属于当前 `frontend/`；另一个工作区的 Vite 进程会被拒绝，当前工作区内由 Vite 热更新的进程可继续复用。
- 该库存能力不是生产功能。应用默认配置始终是 `enabled=false`、测试账套 allowlist 为空；生产部署不得设置 local/test/regression profile，也不得开放 `/api/inventory/adjustments`。管理员权限本身不能绕过环境、开关和账套门禁。
- `scripts/run-regression-tier.mjs` 会在所选 tier 含库存造数脚本时先检查上述健康能力，能力缺失时在运行第一条脚本前失败，而不是产生一批误导性的业务回归失败。

## 密码找回配置边界

A135 已验证密码找回 Redis 门禁的生产默认值：

| 维度 | 默认上限 | 窗口 |
| --- | ---: | --- |
| global | 100 次 | 1 分钟 |
| source | 10 次 | 10 分钟 |
| account | 1 次 | 15 分钟 |

- 只有 active profiles 非空且全部属于 `local/test/regression` 时才允许放宽上述上限或缩短窗口。无 profile 的默认启动、`production`、以及 `local,production` 这类混合 profile 只要配置放宽，都必须在 health 可用前拒绝启动。
- `source` 以应用实际连接的 `remoteAddr` 为准；本地反向代理测试不能用伪造 `X-Forwarded-For` 绕过 source 门禁。
- 密码找回限流器使用独立的 raw RESP 客户端，只支持 standalone Redis 的 host/port 连接。当前合同不支持 AUTH、TLS、Sentinel、Cluster、Redis DB select 或连接池；部署需要这些能力时必须先更换实现并补齐回归，不能只改连接参数。
- 该接口发生在登录和账套选择之前，`JDY_PASSWORD_RESET_REDIS_KEY_PREFIX` 必须是带 hash tag 的平台安全前缀，不得使用任一账套的 tenant Redis 前缀。

## 生成文件

当 Excel 审批或 override 改变时，按顺序运行：

```bash
node export-approved-scope.mjs
node generate-frontend-scope.mjs
# 可选：只在仍需要同步退役中的 app/ 静态范围工作台时运行
node build-app-data.mjs
```

作用：

- `export-approved-scope.mjs` 生成审批文档和 `config/approved-feature-scope.json`，并消费 `implementation-overrides.json` 生成实施解释文档。
- `generate-frontend-scope.mjs` 生成正式 Vue 前端使用的功能范围数据。
- `build-app-data.mjs` 生成旧静态范围工作台使用的数据。
- 不要重跑 `build-jdy-feature-approval.mjs`，它只生成空白审批模板，已有 xlsx 时会被防覆盖闸拦截。
