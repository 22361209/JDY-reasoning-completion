# 本地开发启动说明

## 当前依赖状态

当前机器检查结果：

- Node.js/npm 可用。
- Java 21 已通过 Homebrew 安装：`/opt/homebrew/opt/openjdk@21`。
- Maven/Gradle 未全局安装，但后端已带 Maven Wrapper：`backend/mvnw`。
- Docker Desktop 已安装：`/Applications/Docker.app`。
- Docker CLI、Docker Compose plugin 已通过 Homebrew 安装。
- 当前 Docker context：`desktop-linux`。

本机只使用 Docker Desktop 提供 Docker daemon；不要再启动 Colima。

## Java 环境

当前终端运行后端前先设置：

```bash
export JAVA_HOME="/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home"
export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"
```

验证：

```bash
java -version
javac -version
```

如需让所有新终端默认使用该 JDK，可把上面的 `PATH` 和 `JAVA_HOME` 写入 `~/.zshrc`。

## Docker Desktop

启动 Docker daemon：

```bash
open -a Docker
```

验证：

```bash
docker context show
docker version
docker compose version
```

期望 `docker context show` 输出 `desktop-linux`。

说明：

- Docker Desktop 是手动从官方 DMG 安装到 `/Applications/Docker.app`，不是 Homebrew cask 托管安装。
- 因为当前环境不能输入 sudo 密码，Docker Desktop 自带的 CLI 没有链接到 `/usr/local/bin`；命令行使用 Homebrew 的 `docker` 和 `docker-compose`。
- 如果 `~/.docker/config.json` 出现 `credsStore: "desktop"` 且命令行提示找不到 `docker-credential-desktop`，删除该配置项即可继续拉取公开镜像。

## 生成文件

当 Excel 审批或 override 改变时，按顺序运行：

```bash
node export-approved-scope.mjs
node generate-frontend-scope.mjs
# 可选：只在仍需要同步退役中的 app/ 静态范围工作台时运行
node build-app-data.mjs
```

作用：

- `export-approved-scope.mjs` 生成审批文档和 `config/approved-feature-scope.json`，并消费 `implementation-overrides.json` 生成实施解释文档。
- `generate-frontend-scope.mjs` 生成正式 Vue 前端使用的功能范围数据。
- `build-app-data.mjs` 生成旧静态范围工作台使用的数据。
- 不要重跑 `build-jdy-feature-approval.mjs`，它只生成空白审批模板，已有 xlsx 时会被防覆盖闸拦截。
