## Wave 2（13 项，用户手验，已按 A95-A100 收口主要项）

1. 反审核后不可操作 → 应回审核前可编辑(DRAFT)，非终态 REVERSED（状态机语义，全单据，对齐金蝶）。
2. 客户/供应商选择器：除关键字匹配，要能点开整列表弹窗滚动/搜索选；所有主数据选择器通用。
3. 分录列变多：列设置之外加横向滑块（参金蝶）；所有有表体的页面都要。
4. 表头价格口径可隐藏；单据备注=可调高度文本框（所有页面备注框 resizable）。
5. 首页工作台新建销售订单不自动取号（工作台建单入口没接 A90 取号）。
6. 出库选原单弹窗要横向滑块 + 列设置（所有表体页都要列设置）。
7. 出库选原单弹窗要搜索框（客户编码/名称、产品编码/名称、订单号）+ 全选按钮。
8. ✅ A98：出库源单号不该在表头 → 已改行级（一张出库可来自多张源订单）。
9. ✅ A98：下推出库后"拉入明细"按钮功能不明 + "源单单号"按钮点了回订单、订单又能再下推、出库明细消失 → 已改为"从源订单追加明细"和行级源单追溯新页签，当前出库草稿不丢明细，剩余数量不允许重复超下推。
10. 锁 UX 重想：锁的是被打开的页面本身，非列表标锁定行；不弹提醒（10人各开10张刷爆）；可另做"当前打开单据"专页（金蝶没有，独创）。改写 wave1 #12。
11. 分录表格列宽可自由拉动（像列表）；分录列设置 UI 太抽象 → 直接复用单据列表列设置弹窗样式。
12. 分录表格列缺筛选按钮 → 学单据列表加列筛选。
13. 列表拖动列顺序时显示被拉动列虚影（拖拽 ghost），手感才好。

**主题**：把"分录表/弹窗表"提到"列表表"的 UX 水准（列宽拖动/同款列设置弹窗/列筛选/拖拽虚影/横向滑块）+ 重想锁。
