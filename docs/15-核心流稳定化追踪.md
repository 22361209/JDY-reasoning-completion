## Wave 2（13 项，用户手验，已按 A95-A100 收口主要项）

1. 反审核后不可操作 → 应回审核前可编辑(DRAFT)，非终态 REVERSED（状态机语义，全单据，对齐金蝶）。
2. 客户/供应商选择器：除关键字匹配，要能点开整列表弹窗滚动/搜索选；所有主数据选择器通用。
3. 分录列变多：列设置之外加横向滑块（参金蝶）；所有有表体的页面都要。
4. 表头价格口径可隐藏；单据备注=可调高度文本框（所有页面备注框 resizable）。
5. 首页工作台新建销售订单不自动取号（工作台建单入口没接 A90 取号）。
6. 出库选原单弹窗要横向滑块 + 列设置（所有表体页都要列设置）。
7. 出库选原单弹窗要搜索框（客户编码/名称、产品编码/名称、订单号）+ 全选按钮。
8. ✅ A98：出库源单号不该在表头 → 已改行级（一张出库可来自多张源订单）。
9. ✅ A98：下推出库后"拉入明细"按钮功能不明 + "源单单号"按钮点了回订单、订单又能再下推、出库明细消失 → 已改为"从源订单追加明细"和行级源单追溯新页签，当前出库草稿不丢明细，剩余数量不允许重复超下推。
10. 锁 UX 重想：锁的是被打开的页面本身，非列表标锁定行；不弹提醒（10人各开10张刷爆）；可另做"当前打开单据"专页（金蝶没有，独创）。改写 wave1 #12。
11. 分录表格列宽可自由拉动（像列表）；分录列设置 UI 太抽象 → 直接复用单据列表列设置弹窗样式。
12. 分录表格列缺筛选按钮 → 学单据列表加列筛选。
13. 列表拖动列顺序时显示被拉动列虚影（拖拽 ghost），手感才好。

**主题**：把"分录表/弹窗表"提到"列表表"的 UX 水准（列宽拖动/同款列设置弹窗/列筛选/拖拽虚影/横向滑块）+ 重想锁。

## Wave 3（4 项，用户手验，wave2 的修正，→ 一批 A102）

1. 源单号 + 源单行号拆成两列（现合一列）；所有单据。
2. 选客户/商品/仓库等选择器弹窗太小、信息不全 → 弹窗放大、完整显示，但不是新页面（大模态），参金蝶。
3. 选源单 = 工具栏一个按钮（和新增/保存/审核同行）→ 点开大弹窗（非新页面）；去掉表头追加源订单输入框 + 追加明细/追溯按钮（改 A98/A93 做法），参金蝶。
4. 单据表体手感 ≠ 单据列表标题手感 → 统一成列表那套，且像列表一样支持幽灵拖动改列序 + 鼠标拉列宽；所有单据（A97 没做透）。
5. 单据列表加反审核按钮（批量反审核选中已审核单 → 回 DRAFT，接 A95 语义）。

5b → 升级为 A104（后端多用户单据编辑锁，单独成批，不进 A102）：
  - 单据被用户 A 打开编辑 → A 持编辑锁；列表不再标锁定行、不弹旧提醒。
  - 同权限用户 B 打开 → 提示"已被 A 打开"，可打开但只读（能看不能编辑/审核）。
  - 更高权限账号 → 可踢走 A 夺锁自己编辑。
  - 锁在保存/关闭/超时释放。后端锁表 + 取锁/放锁/夺锁接口 + 权限级别比较；前端编辑/只读模式 + 踢走动作。"当前打开单据"专页可选后做。
6. 筛选图标简约美化。
7. 选择器触发按钮 = 云星辰风格"圆圈三点 ⋯"：表头输入框内部最右侧常显（方便选后换客户）；表体分录里同形同位，但仅光标/鼠标在输入框时显示（focus/hover 才现）。
8. 选客户后刷新分录单价：取该客户该型号最新成交价 → 无则默认价 → 无则 0（价格记忆，从历史成交查；#8 是唯一逻辑项）。

**口径（用户强调）**：wave3 的 UI/手感**参金蝶云星辰（= `复刻-local`，轻量+可用做得好）**；K3Cloud/HW-WIN2019 只学逻辑/机制。A102 工单写死 UI 对照 复刻-local 截图。
