# 验收报告：F2 出入库复用库存过账

- 日期：2026-06-23
- 范围：库存调整、采购入库、销售出库的统一库存过账
- 结论：通过 A1 业务过账能力验收；尚未接入完整出库单/入库单表单

## 本次完成

- 抽出 `InventoryPostingService`，统一处理：
  - 校验启用商品、启用仓库。
  - 创建缺失余额行。
  - 更新 `inv_stock_balance` 的现存量和可用量。
  - 禁止负库存。
  - 写入 `inv_stock_txn` 流水。
- 手工库存调整改为复用该服务。
- 新增业务过账接口：
  - `POST /api/inventory/purchase-in`：采购入库，正向增加库存。
  - `POST /api/inventory/sales-out`：销售出库，负向减少库存。
