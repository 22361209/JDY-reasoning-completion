# F 库存流水与余额闭环验收报告

## 基本信息

- 验收日期：2026-06-23
- 验收范围：库存调整接口、库存余额更新、库存流水写入、库存查询余额口径
- 验收结论：库存已具备第一条“流水 + 余额”一致更新路径；销售出库/采购入库尚未复用该路径

## 通过项

- 新增 `POST /api/inventory/adjustments`。
- 调整库存时：
  - 校验商品、仓库存在且启用。
  - 自动确保对应余额行存在。
  - 原子更新 `inv_stock_balance.qty_on_hand` 和 `qty_available`。
  - 写入 `inv_stock_txn`。
  - 阻止现存量/可用量变成负数。
- `inventory-query-list` 继续从 `inv_stock_balance` 读取，不做结果缓存。

## 验证命令

```bash
curl -s 'http://127.0.0.1:8080/api/lists/inventory-query-list?keyword=CP-001&page=1&pageSize=200'

curl -s -X POST 'http://127.0.0.1:8080/api/inventory/adjustments' \
  -H 'Content-Type: application/json' \
  --data '{"productCode":"CP-001","warehouseCode":"CK-001","qtyDelta":5,"txnType":"ADJUST_IN","sourceBillType":"PLAYWRIGHT_ACCEPTANCE"}'

docker exec jdy-erp-postgres psql -U jdy -d jdy_erp \
  -t -A -c "select txn_type, qty_delta, source_bill_type from inv_stock_txn where source_bill_type='PLAYWRIGHT_ACCEPTANCE' order by created_at desc limit 1;"
```

## 验证结果

- 调整前：`CP-001 / 成品仓` 现存量 `1280`，可用量 `1120`。
- 调整后：`CP-001 / 成品仓` 现存量 `1285`，可用量 `1125`。
- 流水验证：`ADJUST_IN|5.0000|PLAYWRIGHT_ACCEPTANCE`。

## 剩余风险

- 当前库存调整接口是底层能力，尚未接到销售出库、采购入库、盘点等业务单据。
- `source_bill_id` 当前使用系统生成 UUID，后续业务单据接入时必须改为真实单据 ID。
- 尚未实现库存锁定/预留规则。
